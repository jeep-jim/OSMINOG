# OSMINOG 4.0.14 — Space Worlds

Новая кнопка «Вселенная» на холсте и в списке проектов. Настоящие столы становятся планетами: перемещение, масштабирование, поиск, темы, список и притяжение по общим словам, темам и намерениям с объяснением связей.

Профиль мира: идея, темы, кого ищешь, чем поможешь, ссылка на исходники. Метаданные сохраняются вместе с проектом. Карточки можно экспортировать и импортировать. Из чужой публичной витрины можно создать свой стол с указанием источника.

Открытый каталог читает публичные карточки GitHub Issues в jeep-jim/OSMINOG. Публикация открывает предзаполненную форму GitHub: пользователь проверяет текст и самостоятельно завершает публикацию. Комментарии и предложения участия доступны на странице GitHub; нужен аккаунт. Полный общий холст, сервер совместного редактирования, встроенные онлайн-комментарии и присутствие пользователей в этот выпуск не входят.

По умолчанию публикуются только поля профиля. Перенос текстовых заметок включается отдельно и имеет предпросмотр. Файлы, изображения, код, переписка и секреты хранилища автоматически не экспортируются. Приватные данные, вписанные самим пользователем в описание/выбранные заметки, нужно исключить при предпросмотре.

Нет демонстрационных жителей и фиктивной активности. Сходство — локальная эвристика, не AI-оценка личности. Проверены реальное локальное сохранение, восстановление, приватность состава карточки, импорт, отображение недоверенного текста; публичные ответы в браузерном тесте — тестовые. Реальная публичная публикация не выполнялась от имени владельца.
