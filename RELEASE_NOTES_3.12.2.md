# OSMINOG 3.12.2 — Verified Artifact Loop

## Что исправлено

- Команды «нарисуй», «изобрази», «создай портрет/персонажа/вектор» теперь входят в режим полноценной сборки, а не в режим одиночного примитива.
- Перед генерацией ИИ получает контракт целостного редактируемого результата: композиция, пропорции, визуальная иерархия и смысловые слои.
- Для лица и персонажа отдельно проверяются силуэт, форма головы, волосы, парные глаза с радужкой/зрачком/бликом, нос, рот, светотень и пропорции.
- После применения patch OSMINOG делает свежий снимок холста и запускает независимую визуальную проверку результата.
- Если снимок показывает заглушку, фрагменты или неверные пропорции, ИИ получает изображение и обязан исправить существующий объект. Доступно до трёх циклов «проверка → исправление → повторная проверка».
- Статус «Готово» разрешён только после реального применения и маркера успешной визуальной проверки.
- Если patch не применён, снимок получить нельзя или результат не прошёл проверку, задача останавливается с честным статусом «не проверено», без ложного сообщения об успехе.
- Лимит сложного canvas patch приведён к заявленной возможности: до 80 действий.
- Векторные и shape-слои теперь могут получать общий семантический group для редактируемой структуры.
- Удалён оставшийся вызов несуществующего внешнего task monitor; прогресс остаётся в штатной нижней полосе чата.

## Проверки сборки

- JavaScript syntax: PASS.
- JSON parse: PASS.
- Visual artifact contract assertions: PASS.
- Root manifest version/key check: PASS.
- ZIP integrity, size and SHA-256: проверяются публикационным workflow до изменения dev feed.

## Runtime-проверка владельца

После обновления выполнить на чистом участке холста: «Нарисуй лицо человека в векторе, девушку». Ожидается редактируемая многослойная композиция, затем видимый этап визуальной проверки. Надпись «Готово» не должна появиться, если на холсте остались только примитивные фрагменты.
