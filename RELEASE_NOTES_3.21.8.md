# OSMINOG 3.21.8

- Полностью разделены пользовательские чаты провайдеров и фоновые agent-сессии OSMINOG.
- Устаревшая привязка к обычной вкладке автоматически удаляется из служебного маршрута без закрытия или изменения пользовательской вкладки.
- Агентская отправка разрешена только в managed-вкладку внутреннего хаба и только при совпадении сохранённой service session.
- Запрещено неявно назначать активный пользовательский чат фоновой сессией.
- Фоновая вкладка остаётся представленной значком в доке OSMINOG; отдельное окно используется только для ручной авторизации.
