## Runtime result that led to 3.10.3

The first folder tray did not match the owner’s desktop model: it minimized every folder into a bottom bar, virtual folder icons scaled with the canvas, and the folder explorer lacked complete Windows-style views, search and internal moves. These points are corrected in 3.10.3.
