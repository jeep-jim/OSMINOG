Base: 3.10.5.

This build focuses on placement, Google AI context/rich results, connection editing and folder drag/preview behavior.

## Key changes
- Managed windows open at the last owner action point or viewport center, not the upper-left corner.
- Google AI receives project map, selection, connection and linked-node context; visual questions automatically attach a fresh viewport screenshot when no image is already attached.
- Google service-tab bridge returns detected answer images and rich Google cards/widgets to the OSMINOG chat.
- Fake `G` assistant avatar removed from Google chat bubbles.
- Connection inspector adds curve strength and curve offset controls; single-click line selection exposes colour, width, style, dash, arrow and disconnect/delete.
- Folder Explorer shows image thumbnails and supports drag into/out of open virtual folders.
