# OSMINOG 3.20.6 — Graphics + Animation execution

## Цель

Дать пользователю и подключённым ИИ единый внутренний творческий контур: профессионально создавать редактируемую графику, анимировать её и сохранять результат объектом на рабочий стол OSMINOG.

## Реализовано

- Animation Studio поверх существующего Graphics Studio V2.2.
- Дорожки объектов, ключевые кадры, таймлайн, easing, цикл и live-preview.
- Анимируемые свойства: координаты, масштаб, поворот, прозрачность.
- Локальный WebM-экспорт через Canvas Capture / MediaRecorder.
- Lottie-совместимый JSON-контейнер с полным OSMINOG animationDocument.
- Редактируемый объект на рабочем столе с PNG-preview и animationDocument.
- ИИ-инструменты animation_status, animation_open, animation_edit.
- Сохранены все возможности графики: вектор, узлы, перо, кисть, ластик, формы, текст, слои, маски, Boolean, фильтры, прозрачность, SVG и PNG.

## Честные границы версии

- Встроенный MP4 отсутствует: Chrome предоставляет MediaRecorder/WebM, а MP4 требует отдельного кодека/мультиплексора.
- Экспортированный JSON хранит полную редактируемую модель OSMINOG; совместимость сложных Fabric-масок и фильтров с внешними Lottie-плеерами не заявляется.
- Live-проверка в профиле владельца остаётся обязательной перед пометкой runtimeVerified=true.

## Исполнительный доступ агентов

Внутренние агенты получают owner workspace capabilities перед каждым заданием. Для интернет-изображений OSMINOG сначала сам выполняет web_image_search → asset_create на стороне хоста; поэтому агент больше не должен просить повторный доступ к холсту, когда lease уже содержит эти инструменты.
