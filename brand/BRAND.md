# BriefCraft brand

## Canonical logo
The canonical BriefCraft mark is the new yellow `b/c`-style symbol with the sparkle, supplied by the project owner on 2026-08-25.

**Do not use the legacy blue `b°` logo in any future build.**

Canonical assets live in this `brand/` directory. Future Chrome, Windows, macOS, web/landing and ChatGPT/App builds must derive their visible product icon from this brand pack.

## Brand colors
- Primary gold: `#EEBF26`
- Bright yellow: `#FFE100`
- Transparent background by default

## Build rule
Before publishing any new BriefCraft build, make sure its extension/application icons, header mark, favicon and desktop app icon are generated from the canonical logo in this directory. Do not redraw or substitute the mark unless the owner explicitly approves a new logo.
