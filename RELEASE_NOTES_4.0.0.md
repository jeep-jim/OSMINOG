# OSMINOG 4.0.0 — Shared Board

Общая локальная доска проекта: материалы, заметки, связи и чат рядом.

- Чат справа с изменяемой шириной. Холст занимает оставшуюся область. На узком экране чат раскрывается на всю ширину; закрытие возвращает доску.
- Одна компактная панель: выбор, перемещение, файлы, блокнот, Markdown, ноды, связи, фигуры, маркер, снимок экрана/окна, обрезка, копирование картинки, комментарий. Дополнительные действия — «Ещё».
- Блокнот: двойной клик для текста прямо на доске; «Ещё → Открыть крупно» для длинного документа. Полноэкранный редактор сохраняет автоматически и проверяет, не изменился ли объект извне.
- Markdown: исходник и просмотр; документ хранится объектом проекта и читается ИИ. Прежние Markdown-документы доступны через «Ещё».
- Снимок: системный выбор экрана, окна или вкладки. Захват останавливается после получения кадра. Отмена не создаёт пустых объектов.
- Обрезка сохраняет оригинал. Есть Undo и «Ещё → Вернуть оригинал картинки». Картинку можно копировать для вставки в чат через Ctrl+V.
- Фигуры, маркер, ноды и точки связей снова доступны. Два выделенных объекта можно связать кнопкой; сохраняется прежний формат связей.
- Комментарии привязаны к объектам, сохраняются и доступны через get_object. Изменения комментариев и изображений учитываются в контексте ИИ.
- Локальное хранилище, история, ключ расширения и обновление через Dev Hub по кнопке сохранены. Старые объекты не удаляются.

Проверено в Chromium с тестовым адаптером Chrome: сохранение и перезапуск, Markdown, компоновка, связи, чтение комментариев ИИ, обрезка/Undo, PNG-буфер, отмена захвата, старые графические данные; ошибок страницы нет. Системный выбор экрана, действующий вход ChatGPT и применение Dev Hub на компьютере владельца требуют проверки в установленном расширении.

Совместная работа людей через интернет и курсоры участников ещё не включены: старые приглашения были лишь локальным списком ролей. Нужен сервис синхронизации. Публикация плагина ChatGPT — отдельный следующий этап; см. docs/SHARED_BOARD_PRODUCT.md.
