# OSMINOG 3.21.7 — внутренние фоновые ИИ-сессии

Фоновые web-сессии провайдеров представлены внутри OSMINOG отдельными значками в нижнем доке. Нажатие открывает единый центр подключений, а не разворачивает служебное окно Chrome.

OSMINOG переиспользует одну управляемую сессию на провайдера. После успешного подключения её host-окно автоматически сворачивается. Видимое окно допускается только для ручной авторизации на защищённом сайте провайдера.

Ручное подключение пользовательского оригинального чата больше не превращает его в фоновую service session. Пользовательская синхронизация и агентный transport разделены.

Сохранена защита предыдущего исправления: в привязанных пользовательских чатах передаётся только чистый текст без JSON контекста холста, служебных инструкций и tool-result блоков.

Статус: candidate до проверки установочного пакета в авторизованном Chrome владельца.
