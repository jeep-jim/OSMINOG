# OSMINOG 3.20.0 — AI WORKSPACE CORE MERGE

## Основание

Рабочие сценарии версии 3.11.26 сопоставлены с каноническим исходным кодом 3.19.12. Старый файл `gpt-presence.js` не копируется поверх нового: актуальное ядро уже содержит расширенные реализации необходимых контрактов и Shared Vision.

## Сохранённые контракты 3.11.26

- диалоги и состояния агентов;
- перенос агента на объект через `application/x-briefcraft-chat-thread`;
- выполнение изменений через `briefcraft.patch/v1` и `propose_canvas_patch`;
- повторный запрос реального patch после текстового ответа модели;
- drag-and-drop файлов и изображений;
- последовательное выполнение tool-вызовов без зависания интерфейса.

## Интеграция с 3.19.12

- `osminog.vision_context/v1` сохраняет одну revision для структуры и изображения;
- внешний ChatGPT получает Vision preflight до отправки пользовательского сообщения;
- подключённый ранее ChatGPT переподключается к существующей вкладке без создания дубля;
- машинные блоки контекста и результатов инструментов скрыты от обычной переписки.

## Проверки контрольной точки

Статическая проверка `tools/verify_core_merge_3200.mjs` подтверждает версии, синтаксис ключевых JS-файлов и наличие десяти обязательных контрактов. Живые проверки Chrome остаются обязательными до публикации релиза:

1. файл и изображение перетаскиваются на холст ровно один раз;
2. команда создания объекта завершается реальным изменением холста;
3. команда изменения объекта использует существующий ID;
4. «смотри на холст» получает изображение той же revision;
5. ошибка инструмента отображается и не блокирует интерфейс.
