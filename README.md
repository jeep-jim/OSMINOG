# OSMINOG

Private source and project-memory repository for **OSMINOG** — a visual AI workspace where files, code, websites, design, agents, nodes and decisions live on one canvas.

Primary domain: `osminog.red`.

## Active work

The active migration branch is:

`rebrand/osminog-devhub`

It contains the OSMINOG brand rules, source-recovery work and the new unified release/update architecture.

Read before changing the project:

1. `CURRENT_STATE.md`
2. `roadmap.md`
3. `brand/BRAND.md`

## Source rule

GitHub is the source of truth. The owner is not expected to preserve or upload local build folders. Complete platform source, release metadata, checksums, migration rules and recovery artifacts must be committed or generated by CI from committed source.

## Temporary identity

Until the owner supplies the final logo, every new visible product surface uses:

- a plain red circle `#FF2D2D`;
- the word `OSMINOG`;
- no `AI` suffix and no generated mascot.

## Compatibility

The visible rebrand must preserve the existing Chrome manifest key, extension ID, projects, storage keys and internal protocol compatibility until explicit migrations are tested.

## Update architecture

OSMINOG uses one release registry with native platform adapters:

- Chrome development: OSMINOG Dev Hub;
- Chrome beta/stable: Chrome Web Store;
- Windows/macOS: signed native updater;
- Android/iOS: store-native distribution and updates;
- Web/PWA: atomic deployment and service-worker versioning.

No routine update may require selecting an application-source folder or running repair scripts.
