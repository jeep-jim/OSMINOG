# OSMINOG Chrome 4.0.33 — компактная рамка браузера

Обновление расширения поверх 4.0.32. Отдельное Windows-приложение не меняется.

- Убрана внутренняя верхняя плашка OSMINOG Browser App.
- Убраны неработающие кнопки «Открыть» и «Редактировать вёрстку». Переход по адресу выполняется клавишей Enter; вкладки, назад/вперёд и адресная строка остаются.
- Для системной строки заголовка Chrome зарезервирована отдельная полоса внутри рамки. Кнопки окна должны находиться в пределах выделенной области, а содержимое сайта начинается ровно у рабочей области.
- Переключение на другую вкладку основного Chrome или сворачивание родительского окна больше не отправляет сайт в minimized автоматически. При этом ОС/Chrome всё ещё может расположить отдельное окно позади родительского; постоянный always-on-top API для такого окна не обещается.
- Переключение между логическими вкладками сайтов по-прежнему сворачивает невыбранное окно и сохраняет страницу.
- Сохранены перенос медиа через поддерживаемую редактируемую копию, окна авторизации/POST, Authenticator, ключ расширения и существующие разрешения.
- Отдельное Windows-приложение не изменялось.
