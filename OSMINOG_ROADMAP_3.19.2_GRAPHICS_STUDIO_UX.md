# OSMINOG 3.19.2 — Graphics Studio v2.1 UX / Canvas Round-trip Fix

## Что исправлено
- Инструменты Graphics Studio перенесены вниз в компактный icon-only dock. Подписи показываются только через tooltip при наведении.
- Слои вынесены в левую колонку. Для каждого слоя сохранены выбор, видимость и блокировка.
- Свойства объекта остаются в правой колонке.
- Холст редактора по умолчанию белый. Добавлены выбор цвета фона и прозрачный фон с checkerboard-индикацией.
- Добавлено масштабирование как на основном столе: колесо мыши масштабирует относительно курсора, средняя кнопка или Space+drag двигают холст; есть − / 100% / + / Fit.
- Исправлен подвисающий путь «На холст»: перенос теперь выполняется с UI guard, без повторного render, с атомарной заменой исходных объектов и ограничением чрезмерно длинных freehand/path наборов до безопасного числа редактируемых узлов.
- Кнопка «На холст» блокируется на время операции и всегда возвращает понятный success/error status.

## Архитектурное правило
Graphics Studio и AI используют один и тот же редактируемый графический слой. Результат ИИ должен оставаться правимым вручную; ручная правка должна возвращаться на основной холст без flattening, когда формат поддерживается.

## Следующая проверка
1. Нарисовать кистью сложный контур → «На холст» не зависает.
2. Выделить объект на основном холсте → «Открыть в редакторе» → изменить → вернуть на холст.
3. Проверить wheel zoom, Space-pan, кнопки zoom и Fit.
4. Проверить белый, пользовательский и прозрачный фон.
5. Проверить скрытие/блокировку слоя слева.
