# OSMINOG Browser Preview 0.3.0

Новая Windows-оболочка по макету владельца. Исходники: ветка `codex/browser-workspace-030`, PR #24. Это preview, не стабильный выпуск для всех платформ.

## Что изменилось

- Слева — вертикальная лента живых вкладок. Прокрутка слева; соседний разделитель меняет ширину. В узкой ленте показываются значки, в развёрнутой — названия.
- В центре — 1, 2 или 4 области. Область можно развернуть; Escape возвращает сетку. Разделители меняют пропорции.
- Рабочий холст использует прежний редактор и данные проекта. Кнопка «Полный редактор холста» открывает весь редактор со свойствами объектов и прежними инструментами; OSMINOG сверху возвращает браузер.
- Справа — отдельные минивкладки сайтов и диалогов ИИ. Можно открыть ChatGPT, Claude, Gemini, DeepSeek либо HTTP(S)-адрес. Каждый диалог можно закрыть отдельно.
- Шапка: слои, красный знак OSMINOG, версия/обновление, язык редактора, три темы, инструменты, раскладка и сохранение.
- Адреса вкладок, расположение областей и размеры панелей сохраняются локально. При переключении областей страницы остаются открытыми. После полного перезапуска восстанавливаются адреса; несохранённые поля чужих сайтов не гарантируются.
- Снимок страницы добавляется в текущий проект. Контекст видимых страниц и холста можно просмотреть, отредактировать и скопировать для выбранного ИИ.
- Существующий чат проекта сохранён. Правые чаты не включаются автоматически в контекст другого чата.

## Управление

- `Ctrl+L` — адрес/поиск.
- `Ctrl+T` — новая обычная вкладка.
- `Ctrl+Shift+T` — новая вкладка справа.
- Двойной щелчок по вкладке слева — раскрыть её область.
- `Escape` — закрыть окно контекста/добавления/обновления или вернуть сетку.
- Разделители поддерживают перетаскивание и стрелки клавиатуры.

## Границы выпуска

Проекты хранятся на устройстве. Сайты и выбранные облачные ИИ используют собственные сетевые сервисы. Произвольная вкладка не получает автоматический доступ к локальным файлам или редактору. Скопированный контекст — снимок, не постоянный доступ к холсту; изображения и двоичные файлы в текстовый снимок не включаются.

Совместная работа по ссылке, курсоры других пользователей, комментарии и полноценный двусторонний доступ внешнего чата к холсту ещё не реализованы в этой оболочке. Переключатель языка пока меняет язык существующего редактора; новая оболочка преимущественно русскоязычная. Живые авторизованные аккаунты ИИ требуют отдельной проверки: тестовые страницы провайдеров не подтверждают совместимость с их текущими сайтами.

Установочная идентичность и профиль 0.2.x сохраняются. Для неисправной 0.2.0 нужен один ручной запуск исправленного установщика; уже установленный неисправный код не меняется от публикации GitHub. Дальнейшие обновления выполняются через кнопку версии при доступном канале.
