# OSMINOG Chrome 3.14.0 — NATIVE OWNER RUNTIME

Это архитектурное обновление возвращает разработку продукта непосредственно из главного чата OSMINOG и убирает ложные статусы «готово».

## Главное

- Нативные модули OSMINOG открываются прямым интерфейсом без iframe и лишнего контейнера. Sandbox остаётся только для действительно стороннего недоверенного HTML.
- Чат получил отдельные команды `module_create`, `module_update` и `module_test`. После создания запускается проверка; нерабочая установка автоматически откатывается.
- Старый сохранённый `OSMINOG App` с голосовым интерфейсом автоматически мигрирует в нативный `OSMINOG Voice`.
- Голосовой модуль читает последний ответ ИИ по нажатию на лицо, останавливает речь и переносит диктовку в поле чата.
- Нативная декларативная схема поддерживает безопасные действия с чатом, браузером, холстом, речью и собственным интерфейсом.

## Редактор и окна

- Двойной клик по вектору сразу открывает узлы; фигура и карандашный контур преобразуются в редактируемый вектор.
- `Графика` работает постоянным приложением: инструменты слева, рабочая область в центре, свойства справа; «Применить инструмент» завершает перо/кисть.
- Отправка из `Графики` возвращает редактируемые фигуры, текст, линии и контуры, а не одну сплющенную PNG-картинку.
- Новые окна всегда получают верхний z-index; сворачивание отправляет приложение в док; закрытие пользовательского модуля действительно уничтожает его runtime.
- Компактные нативные виджеты имеют отдельную ручку перемещения без визуальной рамки.

## Чат и Owner Runtime

- При открытии история сразу показывается на последнем сообщении без анимированного пролистывания сверху.
- Новые ответы не отнимают позицию чтения: пользователь сам решает, когда прокрутить вниз.
- Команды изменения продукта направляются в реальные исходники/GitHub; команды виджетов и приложений — в проверяемый Module Runtime.
- Добавлены живые design tokens рабочего пространства, управление окнами, произвольная замена иконок и единый журнал инструментов.

## Сохранение, вход и синхронизация

- Автосохранение пишет основной снимок, резервную копию и до 12 ревизий проекта; доступны checkpoint и восстановление ревизии.
- Единый центр объединяет аккаунт, Google Drive sync, AI-сессии, права холста, Poseidon и общий доступ.
- Google Drive выполняет двустороннее объединение проектов по времени изменения.
- Для настоящего Google-входа издатель один раз указывает OAuth Client ID в едином центре; redirect URI показывается там же. Client secret не нужен.

## Иконки

- Цветные арты отображаются напрямую без цветных контейнеров.
- Любую системную или пользовательскую иконку можно заменить собственным PNG/WebP/SVG через единый реестр; прозрачность сохраняется.
- Пользовательский модуль можно удалить, системный защищён от удаления.
