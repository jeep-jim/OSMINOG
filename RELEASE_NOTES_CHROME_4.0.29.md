# OSMINOG Chrome 4.0.29

Обновление поверх единой 4.0.28. Исправление Authenticator сохранено побайтово.

- Светлая тема: серая граница под шапкой и у разделителя чата.
- Шапка чата и основная шапка одной высоты; чат не перекрывает кнопки стола.
- Удалено отдельное окно «Подключения ИИ». Настройки остаются в чате, доступ владельца сохранён.
- Добавлены область веб-просмотра внутри стола, кнопки с глобусом и монитором, новая ссылка, исходный домен и регулируемый разделитель между столом и страницей. Закрытие чата освобождает ширину для страницы.
- Обычный browser_open из чата больше не создаёт скрытое окно служебных ИИ-сессий. Сохранённые ссылки изолированы по проектам и не загружаются без открытия.

Важно: это встроенный изолированный просмотр HTTP(S), не нативный браузер внутри Chrome-расширения. Ограничения X-Frame-Options/CSP не отключаются. Сайты, запрещающие встраивание, могут не открыться. Работа VK и Figma внутри расширения и управление их DOM этой сборкой не подтверждены; нативный Windows-браузер остаётся отдельной реализацией. Само событие загрузки фрейма не выдаётся ИИ за подтверждённое открытие сайта.
