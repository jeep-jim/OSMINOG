# OSMINOG 3.21.4 — ссылки и запросы генерации по образцу

Исправлено распознавание «сгенерируй мне такую же только чтобы он стоял с ноутбуком»: запрос направляется в существующий режим генерации, получает изображение контекста и требует реальный файл результата. Раньше без существительного «фото/персонаж/изображение» он уходил в обычный текстовый режим.

Чат отображает кликабельные HTTP(S) и Markdown-ссылки, жирный текст и блоки кода, включая потоковый ответ и сохранённую историю. Служебные ссылки ChatGPT восстанавливаются только по адресам из метаданных ответа; отсутствующий адрес не выдумывается. HTML из ответа экранируется, опасные схемы и URL с учётными данными не становятся ссылками.

Для команд управления агентами явно описан реально исполняемый протокол calls/tool/args. Фактическая модель из model_slug ответа передаётся в диагностику и сохраняется с ответом личного чата, когда провайдер сообщает её.

Проверки включают точный запрос пользователя, позднее поступление метаданных ссылок, безопасный рендеринг, отсутствие ложного результата генерации, поток/очистку/перезагрузку и прежние проверки папок и приватности.

Ограничение: доступность генератора в живой подписной сессии владельца не проверена. Исправление маршрутизации не является подтверждением полного совпадения инструментов внутреннего API и сайта ChatGPT. runtimeVerified=false.
