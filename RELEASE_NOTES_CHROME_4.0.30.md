# OSMINOG Chrome 4.0.30

- Возвращено штатное окно Browser App и его вкладки; отдельный упрощённый iframe-панельный браузер удалён.
- Компактная полоса вкладок с плюсом сразу после вкладок; адресная строка ограничена по ширине, лишние инструменты редактора скрыты в обычном просмотре.
- Окно браузера пристыковано к левой рабочей области. Кнопка монитора делит область со столом, разделитель перетаскивается. При закрытии чата браузер занимает всё доступное место.
- Восстановлены BrowserApp context/applyEdit адаптеры для browser_read/browser_act.
- ChatGPT и Figma направляются в управляемую вкладку Chrome того же профиля, чтобы использовать системный VPN и расширения браузера.
- CSP/X-Frame-Options не обходятся: защищённые сайты открываются в настоящей вкладке Chrome, а не имитируются внутри iframe.
- Authenticator и native Windows WebContentsView не заменялись.
