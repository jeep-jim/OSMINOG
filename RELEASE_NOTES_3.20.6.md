# OSMINOG 3.20.6 — профессиональная графика и анимация

- В Graphics Studio добавлена кнопка «Анимация» и внутренний Animation Studio.
- Таймлайн работает с реальными редактируемыми объектами: отдельные дорожки, ключевые кадры, позиция, масштаб, поворот и прозрачность.
- Переходы: linear, ease-in, ease-out, ease-in-out и step; доступны цикл, покадровая навигация и просмотр в реальном времени.
- Экспорт видео WebM выполняется локально через Canvas Capture + MediaRecorder. Доступен машинно-читаемый Lottie-совместимый JSON с исходным документом OSMINOG.
- «На рабочий стол» сохраняет превью и animationDocument внутри отдельного редактируемого объекта проекта.
- Подключённые ИИ получили tools animation_status, animation_open и animation_edit. ИИ может открыть таймлайн, поставить ключ, перейти ко времени, запустить/остановить просмотр и экспортировать результат.
- Рисование остаётся в Graphics Studio V2.2: вектор, перо, узлы Безье, кисти, ластик, текст, слои, маски, Boolean-группы, фильтры, градиенты, SVG/PNG и прозрачный холст.

Ограничение: MP4 не кодируется встроенными API Chrome без отдельного кодека; нативный видеоэкспорт этой версии — WebM. Lottie JSON хранит редактируемую OSMINOG-анимацию, но не заявляется как универсальный рендер всех Fabric-эффектов во внешних Lottie-плеерах.
