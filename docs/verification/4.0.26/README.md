# 4.0.26 — редактор кода и оболочка

## Использование

Откройте **Код** в шапке. Вставьте HTML целиком или один Markdown-блок `html` из чата и нажмите **Запустить**. HTML/CSS/JavaScript выполняются в изолированном предпросмотре. Ошибки выполнения отображаются возле него.

**Открыть папку** загружает дерево проекта; папку также можно перетащить в редактор. Выберите файл, редактируйте его и сохраните через Ctrl+S. Для локального веб-проекта выберите HTML-файл и запустите предпросмотр: соседние JS/CSS/изображения доступны по относительным путям.

CodeMirror подсвечивает HTML, JavaScript, TypeScript/JSX, Python, CSS и JSON; поддерживает поиск, историю редактирования, парные скобки и сворачивание. Подсветка языка не означает наличие среды его исполнения. Python MCP-сервер требует Python и подключения к реальному исполнителю; он не является HTML-игрой. React/TSX-проект с зависимостями требует сборки, npm-сборщик в этот выпуск не включён.

## Дизайн

Нейтральные графитовая и светлая темы, единые контурные SVG, согласованные размеры панелей и кнопок. Размеры текста и кнопок, собственные цвета остаются в настройках палитры. В узком окне команды шапки переходят во второй ряд. Сайты внутри вкладок сохраняют собственный дизайн.
