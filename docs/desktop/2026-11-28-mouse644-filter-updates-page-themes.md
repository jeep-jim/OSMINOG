# Mouse 6.0.44 — Mac: темы сайтов, имя и обновляемые фильтры

## Поручение и границы

28 ноября 2026, KRAT (UTC+7). Владелец попросил доработать автоматически обновляемые сетевые фильтры и добавить в эту же сборку переключение темы страниц: на присланном скриншоте светлая оболочка Mouse соседствует с тёмным GitHub. Первоначальный разбор был только чтением; последующее прямое «сделай … в эту же сборку» разрешило реализацию.

Работа только над macOS Apple Silicon. Windows/Linux остаются на опубликованной 6.0.42, их сборки и публикация приостановлены. АвтоЦена и её доступы не используются. Профиль, App ID, Chromium partition, cookies, сохранённые столы, вкладки и действующий канал обновления сохраняются. Маскот/Dock не меняются.

## Реализация кандидата

### Темы

`nativeTheme.themeSource` передаёт выбранную светлую/тёмную тему всем страницам через стандартный `prefers-color-scheme`. `mouseControlSettings.syncWebsiteTheme` по умолчанию включён и дополнительно синхронизирует явные темы зарегистрированных главных HTTP(S)-документов. GitHub использует точный Primer-контракт; другие сайты — корневые `data-theme`, `data-bs-theme`, `data-color-mode`, `data-color-scheme`, `color-mode`, `theme` и классы `light`/`dark`, когда CSS подтверждает обе темы. Bootstrap допускается по документированному контракту и загруженным CSS-переменным. [Electron](https://www.electronjs.org/docs/latest/api/native-theme), [Bootstrap](https://getbootstrap.com/docs/5.3/customize/color-modes/).

Сохраняются совместимые контрастные варианты GitHub, последние заданные сайтом атрибуты и посторонние классы. Отключение возвращает оформление сайта. Учтены новые/открытые страницы, поздний CSS, навигация, замена корня, BFCache и отдельное владение обычных/приватных страниц. IPC разрешён только зарегистрированному WebContents и его главному фрейму.

Cookies, localStorage, настройки аккаунта и сетевые ответы не изменяются; инверсии изображений нет. Чтение CSS ограничено по объёму. Нестандартный внутренний JS-переключатель и недоступный сторонний CSS без известного контракта не объявляются универсально поддержанными.

### Название установленного приложения

В меню, About, Dock и локализованном имени bundle — **Mouse**. `InfoPlist.strings` для всех упакованных локалей содержит `CFBundleName/CFBundleDisplayName=Mouse`; базовое имя, физический `Mouse Browser.app`, исполняемый файл и App ID сохраняются для совместимости старого обновлятора643. Профиль Mac по-прежнему `Trader OS`. [Контракт Finder](https://developer.apple.com/library/archive/documentation/General/Reference/InfoPlistKeyReference/Articles/CoreFoundationKeys.html), [нативное получение имени](https://developer.apple.com/library/archive/qa/qa1544/_index.html).

`tools/mouse-644-branding.swift` проверяет отображаемое имя через FileManager и Bundle, локали, App ID, версию и прежние пути — отдельно после установки и после реального обновления643→644. Установленные файлы/профиль для переименования не переписываются.

### Списки фильтров

Существующий ограниченный сетевой matcher и владелец Electron `webRequest` сохранены. Движок Ghostery не добавлен: его полный Electron-адаптер предоставляет также внедрение CSS/JS, redirect и CSP, что шире выбранной задачи. Внешний TXT сам по себе не меняет правовую оценку поведения приложения.

Добавлены 12-часовая проверка актуальности, ETag/Last-Modified и условные запросы. `304` допустим только при наличии проверенного локального тела и ранее полученного валидатора; дата успешной проверки отделена от даты содержимого. При ошибке остаётся последняя рабочая копия и применяется ограниченная задержка повторов. Полученные данные проверяются и компилируются до замены активных правил. `304` экономит повторную передачу тела списка, но не устраняет обмен запросом и заголовками.

Настройки показывают источники, состояния, даты, число поддерживаемых правил и сведения об авторах/лицензии. Можно проверить обновления вручную, включить/выключить список, добавить до восьми собственных HTTPS-подписок и удалить пользовательскую подписку. Списки являются данными ограниченного сетевого синтаксиса, не исполняемым JavaScript. При отключении всех подписок matcher пуст; общий выключатель останавливает обработчики, загрузки и таймер. В инкогнито постоянное управление подписками недоступно.

Загрузчик не пользуется cookies браузера, не передаёт посещаемый URL и не следует redirects. Пользовательские URL проверяются; реальные соединения привязаны к проверенным публичным DNS-ответам. Ограничены число, размер и формат списков. Последняя валидная копия хранится локально; запись настроек и кэша атомарная. Источники подписок видят обычный сетевой запрос за списком — это не обещание отсутствия любого исходящего трафика.

В сборку включены неизменённые EasyList/RU AdList версии `202611280152` как резерв при отсутствии скачанного кэша. Полные исходные заголовки и атрибуция сохранены, размеры/SHA256 закреплены в `desktop/mouse-filter-lists/manifest.json`; [условия и источники](../../desktop/mouse-filter-lists/README.md). Резервные копии используются только для включённых источников.

## Проверка и текущий статус

**Кандидат в разработке; новая версия пока не опубликована.** Публичным Mac-выпуском остаётся 6.0.43.

Новая установленная проверка644 использует два отдельных процесса, собственный профиль и реальные Mac CGEvent. Для воспроизводимости документ с точным origin GitHub подаётся через принадлежащий тесту `session.protocol` handler, а HTTP-сервер подписок отдаёт 200/304/503. Эти документы и списки явно отмечены как fixtures; они не являются проверкой личного GitHub-аккаунта владельца или обещанием блокировки рекламы на публичном сервисе.

Проверяются GitHub, стандартная CSS-тема и две общие страницы с атрибутом/классами: обе темы, фактический `matchMedia`, атрибуты/вычисленные цвета и пиксели native display, неизменность живых страниц/форм/прокрутки/cookies/storage, восстановление исходной темы, reload, приватная сессия, состояние после перезапуска, работа кэша/резерва, валидаторов, пользовательского списка и выключателя. Независимый reader проверяет исходные PNG/JSON, привязку к процессам и файлам. Все прежние обязательные suites и приёмка обновления из опубликованной643, а также legacy629 сохраняются.

Повторный общий локальный Mouse suite после возобновления: **1804 PASS, 0 FAIL, 11 SKIP** (1815 случаев). Независимый reader644:13 PASS; updater-wrapper:9 PASS. Базовый `npm test`:177 PASS/5 FAIL, все пять — `listen EPERM` на Unix sockets в неизменённом `mcp-host.test.cjs`; он остаётся обязательным на Mac.

Исходный run [46097549869](https://github.com/jeep-jim/OSMINOG/actions/runs/46097549869) завершил содержательную проверку643 после рестарта, но завис на закрытии HTTP-fixture с idle TCP-соединением. Старые native проверки имени согласованы с новым Mac-именем, сохраняя старое имя baseline636 и других платформ.

Рабочие инструкции сокращены; полная история root AGENTS вынесена в `docs/context/2026-11-28-root-instructions-history.md`. Legacy Trader Mac/Windows jobs не запускаются для Mouse-веток. Проверки и публикации Mouse Windows/Linux остаются приостановлены.
