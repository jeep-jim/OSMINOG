# Mouse Browser 6.0.7 — только направление исходного логотипа

Продолжение OSMINOG_BROWSER_ROADMAP.md и журнала публикации 6.0.6. Владелец показал неверную иконку в DMG: хвост вправо, тогда как его большой чёрно-белый эталон и надпись МАУС показывают хвост ВЛЕВО. Это ошибка реализации, не новое название/маскот/дизайн. Исправление — горизонтальное отражение существующей пиксельной маски; исходный mouse.png остаётся неизменным для происхождения. Ни одного пикселя не дорисовывать.

Все производные Mac-иконки (Finder/DMG .icns, светлый/тёмный Dock, UI PNG) отражаются одинаково. Приватный SVG отражается целиком вместе с очками, строго один раз; повторная сборка не меняет направление обратно. Генерация выполняется перед упаковкой. Пользовательские данные/профиль, интерфейс, меню, кошелёк, вкладки, Windows/Chrome/Android и АвтоЦена не меняются.

Проверка: 175 исходных пикселей без потерь, точное отражение 22×30 в размерах 64/1024 и обеих темах. В установленном приложении проверяются actual .icns из Info.plist, упакованные PNG, реально отрисованный SVG; хвостовая строка обязана начинаться слева. Сохраняется PNG, извлечённый из настоящего .icns, для визуальной сверки. Все проверки 6.0.6 сохраняются.

Статус этой записи: подготовлен узкий patch и локальные pixel-тесты пройдены. Mac CI и публикация подтверждаются отдельно. Прежние незакрытые дефекты (HTTP403 updater, дополнительная native-полоса, favicon issue138) не выдаются за исправленные. Сборка ad-hoc, без Developer ID/notarization; установка DMG вручную, профиль Trader OS сохраняется.
