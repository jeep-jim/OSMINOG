# Mouse 6.0.7 — уточнение очков перед публикацией

Продолжение 2026-11-14-mouse607-logo-direction.md. Владелец разрешил публикацию и прислал конкретный вид маскота инкогнито: хвост влево, чёрные пиксельные очки с белыми диагональными бликами и выступающей дужкой справа. Предыдущие упрощённые очки не были точным совпадением — это прямо сообщено владельцу, без ложного подтверждения.

В mouse-private.svg сохранена исходная маска 22x30/175 пикселей; соседние исходные прямоугольники представлены эквивалентными контурами, под одним горизонтальным отражением. Новый рисунок очков получен выборкой центров сетки 33x7 из присланного скриншота image(20261114-095851).png, без подмены маскота и без генерации нового макета. Положение соответствует образцу. Тело белое на существующей тёмной приватной странице, как прежде; серый фон/сетка/элементы Figma из скриншота не включены. Точное совпадение цвета с серым редакторским превью не обещается.

Сборочный генератор распознаёт уже отражённую группу mouse-approved-left, поэтому повторная сборка не поворачивает мышь обратно; очки с правой дужкой не отражаются повторно. Пиксельная App/Dock/UI мышь остаётся без очков, только инкогнито использует очки. Исправлена устаревшая проверка номера 6.0.6 в packaged smoke на текущий 6.0.7, проверки поведения не убраны.

Публикация допускается после повторной нативной проверки и установки DMG. Не объявлять HTTP403, дополнительную системную полоску или favicon issue138 исправленными этим выпуском. Пользовательский профиль и поведение браузера не меняются.
