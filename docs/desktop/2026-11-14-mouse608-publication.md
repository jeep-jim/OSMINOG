## Что включено

Инкогнито: исходная мышь белая, хвост влево, чёрные пиксельные очки с белыми бликами. Маска масштабируется равномерно в квадратные клетки2x2: отдельные точки усов не растянуты в прямоугольники. Название Mouse Browser сохранено, персонажу не присваивается имя. В Dock ВСЕГДА чёрная мышь на белой подложке, независимо от обеих тем. Обычный логотип без очков.

В строке каждого окна кнопка ⤢ «Развернуть окно на весь экран». Выбранная панель временно разворачивается; повторная кнопка/выход возвращают её на прежнее место и размер без перезагрузки. Дерево раскладки/slots не заменяются fullscreen-состоянием. Учитывается предшествующий fullscreen всего приложения; смена приватного режима снимает временное разворачивание.

Глобальный Control+A использует нативный одноразовый ScreenCaptureKit на macOS14+. При необходимости есть системный выбор экрана с явным согласием, а не бесконечная проверка старого разрешения Electron. В настройках браузера кнопки «Выбрать экран через macOS», «Проверить разрешение», «Снять экран сейчас», «Разрешение macOS…». Запись экрана и разрешение запуска приложения — разные разрешения. Cmd+A не перехватывается. Только при запущенном приложении, без фонового агента/записи аудио/облачной отправки. macOS13 сохраняет прежний путь. Проверено настоящее получение кадра с уже выданным согласием; выбор экрана и конкретный отказ на личном M1Pro владельца не проверены автоматически.

Новый обновлятор сначала читает статический HTTPS-канал; API GitHub только резерв. Скачивание проверяет версию/архитектуру/адрес/размер/SHA256, перед установкой хэш проверяется снова. Кнопка «Установить и перезапустить» подготавливает копию приложения, проверяет bundleID/версию/arm64/ad-hoc codesign, сохраняет сессию, заменяет приложение и запускает его. Прежняя копия сохраняется для восстановления. Нужны права записи в /Applications или ~/Applications. Нет повышения привилегий и обхода Gatekeeper/TCC.

## Переход и незакрытые ограничения

Уже установленная6.0.7 НЕ содержит нового обновлятора: её прежний HTTP403 этой публикацией удалённо не исправляется. Один переход на6.0.8 через DMG обязателен; затем предусмотрено «Обновить → Скачать обновление → Установить и перезапустить». Проверенный тест нового установщика не выдавать за исправленную старую кнопку6.0.7.

Полностью завершить Mouse через Cmd+Q, скопировать Mouse Browser.app в «Программы» с заменой и запустить оттуда. Не удалять `~/Library/Application Support/Trader OS`, не запускать Quadro и Mouse одновременно. Новый updater не устанавливает приложение автоматически без команды пользователя. Пока нет Developer ID/нотариализации, macOS может требовать отдельного подтверждения запуска и доступа к экрану. Полную защиту Mac не отключать.

Issue138 favicon во всех библиотечных списках и дополнительная полоса нативного меню остаются открытыми. Кошелёк только Sepolia, неаудированный, не для настоящих средств. Инкогнито не гарантирует анонимности/стирания RAM/swap/системных следов. Физический M1Pro владельца, все сторонние приложения/сайты и все состояния TCC не тестировались удалённо. Другие платформы и АвтоЦена не публиковались.
