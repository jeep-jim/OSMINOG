# Mouse Browser 6.0.22 — кандидат, ещё не опубликован

## Прямое поручение владельца

Выполнить все последовательные уточнения: большая выезжающая норка с плавными нижними сопряжениями и скруглённым верхом, круглые плюс/закрыть, ровно пять столов, пять режимов, реальные превью без обязательного переключения, зелёный активный стол, прежняя плавная анимация и пиксельная мышь работающего агента. Существующие вкладки получают только новую сетку; стартовые сервисы допустимы только на полностью пустом столе.

## Реализация кандидата

- DesktopBank schema2 дополняет или ограничивает список пятью столами. Старые лишние столы сохранены полностью в recovery, их вкладки перемещаются в пятый без закрытия страниц. Плюс выбирает свободный существующий стол.
- Режимы: трейдер (5 окон), мессенджеры/поддержка (7), разработка/дизайн (5), контент/соцсети (6), агенты (3 и правая панель). Support: Telegram, Instagram, WhatsApp, WeChat слева; карты, Gmail и поиск справа. Остальные конфигурации заданы в `desktop/mouse/modes.js`. Адреса — обычные веб-страницы, не интеграции с аккаунтами.
- Нажатие миниатюры показывает увеличенный предпросмотр; отдельное «Перейти» переключает стол. Последний видимый JPEG страницы хранится только в RAM, максимум60 изображений/400px/256KiB каждое. Скрытые страницы не загружаются ради превью. Lock/unlock, приватность и завершение очищают host cache и renderer DOM; поздние captures отвергаются. Боковые и внутренние вкладки учитываются как существующие.
- Сохраняются native slide621, доступность с клавиатуры, reduced motion, утверждённая голова/Dock и приватное оформление619, профиль Trader OS, shared ordinary session, отдельная private MemoryStore, sandbox/contextIsolation страниц.

## Agent Mouse

Внешний Node utility process выполняет ограниченный цикл модели, Mouse предоставляет scoped CDP-compatible gateway и отдельный терминальный сервис. Connector на127.0.0.1:9222 выключен по умолчанию, включается владельцем для текущего обычного стола «Агенты». Подключение по per-session WebSocket URL; Origin отвергается. Не открывается глобальный неаутентифицированный Chromium remote-debugging порт.

SDK на chrome-remote-interface умеет список/открытие вкладок, DOM/read, реальные Input mouse/text события и screenshot. Runtime.evaluate ограничен read-only side-effect guard. Доступ к другим столам и привилегированным target отсутствует. Перед подключением выбирается «Автономно в этом сеансе»: после общего согласия агент выполняет клики, ввод и команды без подтверждения каждого шага. При снятой галочке действия показаны до пошагового подтверждения; навигация или изменение видимой панели отменяет устаревшее подтверждение. Автономное разрешение не сохраняется на диск, действует только в текущей включённой сессии и сбрасывается при Stop.

node-pty shell работает в выбранной папке; xterm показывает тот же вывод. Папка не является OS sandbox. Stop отключает listener, pending actions, utility worker и конкретные дочерние процессы PTY. Навигация оболочки, crash, смена стола/режима, приватность и блокировка тоже останавливают сессию. Model/API credentials вводятся владельцем, не входят в сборку и не пишутся на диск. REG/mobile secrets не используются. Cloud API получает данные только после явного запуска и согласия.

Кнопка Localhost проверяет порт и открывает страницу в сетке. Пиксельная мышь отражает реальные enabled/running события; анимация отсутствует при reduced motion. Клиенту доступны логи, поле задачи и постоянная кнопка Стоп.
