# Mouse 6.0.35 — кириллический запрос в публичном поиске

Дата: 21.11.2026. Дополнение к `2026-11-21-mouse635-search-and-library.md`; предыдущие отказы и требования приёмки остаются действующими. Статус: исходники и локальные проверки подготовлены, приёмка установленного приложения ещё необходима.

## Наблюдаемый отказ

Повторный публичный JSON-запрос Mwmbl с исходной строкой владельца `новости про антропик` вернул 37 строк. Ни одна не содержала `anthropic` или `антропик` в URL, заголовке или выдержке. Совпадали общие слова «новости про». Запрос `антропик` вернул 0 строк. Эти ответы не считаются работающим поиском по теме.

Англоязычный Mwmbl-запрос `Anthropic` вернул 57 строк, а `Anthropic news` — 42. Для проверки общего механизма публичный MyMemory GET перевёл **полную исходную строку**, без словаря брендов и подстановки ожидаемого названия, в `News about Anthropic`. Mwmbl по этой точной полученной строке вернул 50 строк, из которых 33 содержали существенный токен `anthropic`. Это ограниченная выдача Mwmbl; наличие слов `news` не доказывает свежесть каждой страницы.

Это реальные HTTP-проверки через разрешённый сетевой транспорт рабочего окружения, **не** приёмка установленного Electron. Прямой локальный запуск production Node reader получил `SEARCH_DNS/EAI_AGAIN`, поэтому не записан как успешный end-to-end прогон. GDELT DOC/Context в исследовании ответили HTTP 503 и в продукт не включены. Наличие личного Brave-ключа не подтверждено, секреты не читались.

## Подготовленный механизм

1. При наличии личного ключа сохраняется прежний Brave API. Без него — DuckDuckGo Instant Answer как отдельная справка и настоящий JSON-поиск Mwmbl.
2. Для кириллической строки отбрасываются результаты, не содержащие все существенные слова запроса в URL/заголовке/выдержке. Общие слова поиска и новостного намерения исключаются по общему небольшому списку, без специальных имён и URLs.
3. Если подходящих результатов нет, короткий русский запрос может **один раз** переводиться через публичный `https://api.mymemory.translated.net/get`, `langpair=ru|en`. Предел — 500 UTF-8 байт. Длинная строка не разбивается для обхода лимита. Действует прежний общий 30-секундный срок запроса; перевод ограничен максимум шестью секундами и остатком общего бюджета.
4. Повторный Mwmbl-запрос использует точную строку из `responseData.translatedText`. Результаты снова фильтруются по существенным словам. URL создаются только из фактически полученных строк API; модель не генерирует ссылки.
5. Исходный пользовательский `query` остаётся неизменным. Ответ содержит `translatedQuery` и `translation` с источником/языками. В UI точная дополнительная строка и MyMemory названы рядом с выдачей; неполное покрытие Mwmbl обозначено. Последующие страницы используют тот же сохранённый snapshot, перевод повторно не отправляется.
6. Отказы 403/429, CAPTCHA/HTML и некорректные ответы не обходятся другим сервисом. Если перевод недоступен по сети, возвращаются честное отсутствие совпадений и объяснение, а не прежние нерелевантные строки. Отмена прекращает и перевод, и продолжение поиска.

## Данные и публичные контракты

Используется только GET `/get`; `/set`, загрузка словарей, POST, тело запроса, ключ, email/IP пользователя и другие параметры в этом маршруте запрещены transport-валидацией. По спецификации `/get` ищет перевод; вклад в публичный архив относится к отдельным `/set`/import операциям, которые не используются. Условия MyMemory допускают долговременное сохранение отправленных сегментов. Это прямо обозначено в настройках поиска, вместе с альтернативой личного Brave-ключа.

Первичные документы:

- [Mwmbl API и anonymous tier](https://developer.mwmbl.org/): публичный JSON API, анонимный лимит 1000 запросов в месяц на IP, один запрос в секунду. Существующая очередь не ускорена.
- [MyMemory REST specification](https://mymemory.translated.net/doc/spec.php): GET, `q`, `langpair`, предел 500 байт; отдельное описание публикации через `/set`.
- [MyMemory usage limits](https://mymemory.translated.net/doc/usagelimits.php): анонимный объём 5000 символов в сутки. Квота не обходится аккаунтами, адресами или повторными запросами после отказа.
- [MyMemory terms](https://mymemory.translated.net/terms-and-conditions): использование и сохранение отправленных сегментов.

В installed635 smoke сохранены прежние исходный русский ввод, две страницы, проверка темы, отсутствие повторных URL и реальный отказ основного API. Для переведённой выдачи дополнительно обязательны три независимых сырых receipt: исходный Mwmbl-ответ, MyMemory-ответ с исходной строкой/`ru|en`, Mwmbl-ответ с точным переводом. Проверяются Chromium transport, GET/status/content-type, размер и SHA-256 каждого тела. Каждый выданный URL обязан существовать в последнем реальном JSON; недоказанный перевод и скрытая замена запроса отклоняются. Это расширение доказательства происхождения данных, а не замена оригинального запроса владельца тестовой английской строкой.

Поведенческие тесты используют другую тему («космос»), проверяя отсутствие привязки к Anthropic: отсутствие перевода при релевантной русской выдаче, отсечение шума, обе страницы одного snapshot, точную подпись, кэш, отказ квоты/формата, предел байтов и отмену. Тесты provenance отдельно отклоняют отсутствующий оригинальный запрос, неправильный перевод и выдуманный URL. Результат установленного приложения и публикация должны быть дописаны после фактического CI.
