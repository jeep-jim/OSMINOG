## Изменения в работе

- Native CSS-регион нижней панели, исключения для интерактивных элементов и открытого модального интерфейса. Проверка движения будет использовать реальные события macOS и сравнивать координаты окна; проверка стиля сама по себе не считается доказательством.
- Адаптер обычных document tabs без нового WebContents на каждый документ; встраиваемые редакторы, общий strip/панели/переключение/закрытие и охрана несохранённых изменений.
- Реальная замена текстовых операторов поддерживаемых PDF; неподдерживаемые/сканированные фрагменты не должны молча имитировать редактирование белой заливкой.
- Mouse-only объединение однотипных событий страниц и пропуск записи неизменённых стартовых настроек; команды пользователя остаются немедленными. Существующие media/GPU/security настройки и живые вкладки сохраняются.
