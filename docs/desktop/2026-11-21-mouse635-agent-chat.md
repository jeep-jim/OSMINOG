## Реализация

- `agent-ui.js` и `agent-chat.css`: три зоны чата, модальное окно через существующий native overlay barrier, скрытый технический журнал, скрытый терминал, отдельные остановка ответа и отключение прав.
- `mouse-agent/chat.cjs`: OpenAI-compatible SSE с корректной обработкой разорванных UTF-8/SSE границ, JSON fallback, ограничением размера, обнаружением прерванного/пустого ответа. Обычный разговор работает без CDP и доступа к страницам/файлам.
- `mouse-agent/chat-host.cjs`: авторитетная история в памяти текущего сеанса, изоляция по рабочему столу; потоковый ответ, отмена, защита от поздних событий, новая беседа. История не обещается сохранённой после перезапуска приложения. Ключи не входят в историю/журналы/state.
- При явно включённом управлении браузером чат использует существующий runner и песочницу MCP. Перед передачей данных рабочего пространства конкретной модели — явное разрешение в чате. Автономность не пропускает это согласие и новые права на запись/команды. Обычные внешние CDP-клиенты не получают нового пути расширения прав.
- Ответы модели/файлы отображаются как текст; fenced code имеет отдельный блок и копирование. Технические события остаются только в сворачиваемых деталях.

## Дополнение владельца: скриншот, меню окон и закрепление

Владелец уточнил порядок: кнопка скриншота сразу после загрузок в нижней правой группе. Доступное имя группы перечисляет поиск, эмодзи, масштаб, историю, закладки, загрузки и скриншот. Слева в брендовой группе остаётся только ссылка Mouse Browser.

Вместо видимого HTML select — кнопка с миниатюрой фактического дерева текущего стола и системное меню в том же стиле, что правый клик по окну. Два окна различают расположение рядом и друг над другом. Изменённые вручную пропорции или собственная схема явно отмечаются как «Своя раскладка», а не выдаются за стандартный preset. Скрытый прежний select сохраняется только как внутренний совместимый control.

«Закрепить окно» / «Открепить окно» в контекстном меню означает фиксацию границ окна и привязанной вкладки на текущем столе. Навигация внутри страницы и временный полноэкранный просмотр сохраняются. Перестройка свободной части стола разрешена, если не меняет границы закреплённой области. Закрытие/перенос закреплённой вкладки и замена её другой требуют явного открепления. Состояние закреплений входит в профиль соответствующего стола; приватный сеанс не пишет их в обычный профиль.

## Независимая проверка backend чата

Исправлены воспроизведённые ошибки: текущая задача выпадала из контекста после пяти tool-действий; нестриминговый ответ с finish_reason=length/content_filter ошибочно считался законченным; остановленный worker мог сохранить CDP-доступ до фактического выхода процесса; пустой done от модели заменялся выдуманным сообщением об успехе. Теперь текущая задача сохраняется при сокращении истории, усечённый ответ остаётся частичным с ошибкой, доступ конкретного worker отзывается синхронно и повторно проверяется после await, итог требует настоящего непустого текста модели.

После этих исправлений: chat+agent40PASS; MCP/terminal16PASS и2Windows-onlySKIP; отдельный chat12PASS. Это локальные проверки поведения. Публикация и работа установленного приложения подтверждаются отдельно по native-артефактам.
