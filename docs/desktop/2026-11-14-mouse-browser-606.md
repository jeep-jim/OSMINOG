# Mouse Browser 6.0.6 — прямое исправление владельца

Владелец явно выбрал точное название **Mouse Browser** и предоставленную пиксельную мышь вместо зелёно-розового крестика. Никакие новые рисунки/макеты/названия не нужны. Мышь — маскот, отдельного имени владелец не задавал. Источник: вложение mouse.png (22×30); форма/пиксели сохранены, только масштабирование по целой сетке и чёрный/белый цвет. Это заменяет прежнее требование сохранять крестик. Приложение/меню/Dock/новая вкладка/загрузка/обновление используют мышь. Профиль, bundle ID, IPC и существующие сессии не переименовываются.

Владелец НЕ просил скрывать системную строку Apple: часы, заряд, Wi-Fi и системные пункты должны быть доступны в полноэкранном режиме. Старый расчёт 64–88px вырезан; используется состояние нативного меню/его фактическая высота. Public AppKit исключает HideMenuBar/DisableAppleMenu, оставляет обычную системную строку и пользовательские настройки; без kiosk, глобальных defaults и окон поверх меню. Пустая строка собственного браузера не добавляется. Нативные тесты обязательны; поведение личного выреза/настроек на M1 Pro не выдаётся за проверенное автоматически.

Правый ИИ: ровно одна компактная строка — favicon сервиса перед именем, добавление ссылки, обновление, закрытие. Отдельная строка «ИИ-чат» удалена. Иконки загружаются с самого сервиса/его текущей favicon, ограниченно и как инертные изображения. Сайты/контент чатов не перерисовываются и не брендируются нашей мышью.

Публикация только Mac Mouse Browser из OSMINOG / OSMINOG-Releases. Канал с историческим quadro tag и проверенной alias-ссылкой сохраняется для обновления с6.0.5; primary DMG именуется Mouse-Browser. Без изменения других платформ и АвтоЦены. Ребрендинг не равен независимому аудиту кошелька: только Sepolia, как прежде. Подпись ad-hoc, не Developer ID/notarization. Домен не покупался и его доступность не подтверждена; выбранное владельцем имя не заменяется предположением о свободном домене.

Статус: изменения подготовлены; нативные проверки и публикация фиксируются ниже после фактического результата.


### Контраст, эффект снимка и инкогнито — текущая сборка

Стрелка поиска и меню плитки получают собственные контрастные пары поверхности/текста в обеих темах, не наследуя противоречивые glass-стили. После успешного получения пикселей показывается короткая вспышка/рамка с учётом reduced-motion и «Снимок готов». Эффект находится поверх canvas и не входит в PNG; ошибки захвата не показываются как успех.

Инкогнито переключается кнопкой очков и Cmd+Shift+N, без нового внешнего агента. Вся раскладка временно работает в отдельной in-memory Chromium partition cache:false; normal pages отделены от окна, но остаются загруженными. Состояние приложения/вкладок/закладок/загрузок — только MemoryStore; история, запросы и список закрытых страниц не записываются даже в библиотеку. Новая вкладка содержит исходную мышь с наложенными чёрными пиксельными очками; это маскот, не личное имя. Кошелёк/его provider отключены в приватных страницах, обновление/выбор файла фона доступны в обычном режиме. Перед сменой маршрутов IPC предыдущий renderer загружается в about:blank, исключая позднюю запись приватных настроек в normal store.

Выход из режима останавливает private webContents, отменяет незавершённые загрузки, очищает cookies/site storage/HTTP cache/auth/resolver/connections, опустошает MemoryStore и восстанавливает обычные вкладки без их перезагрузки. Новая приватная сессия получает другой UUID. Явно сохранённые файлы и буфер обмена не стираются; серверы, провайдер, администратор сети и macOS могут оставлять собственные следы. Гарантии физического стирания RAM/swap не заявляются.

Тесты должны отдельно подтвердить memory partition, отсутствие обычных cookies/localStorage, отсутствие wallet provider, private cleanup, неизменность normal pages/cookies, отсутствие приватного sentinel в workspace.json после возврата и настоящего закрытия процесса. Эти проверки не заменяются внешним видом страницы.
