# Mouse Browser 6.0.6 — прямое исправление владельца

Владелец явно выбрал точное название **Mouse Browser** и предоставленную пиксельную мышь вместо зелёно-розового крестика. Никакие новые рисунки/макеты/названия не нужны. Персонаж — Макс. Источник: вложение mouse.png (22×30); форма/пиксели сохранены, только масштабирование по целой сетке и чёрный/белый цвет. Это заменяет прежнее требование сохранять крестик. Приложение/меню/Dock/новая вкладка/загрузка/обновление используют мышь. Профиль, bundle ID, IPC и существующие сессии не переименовываются.

Владелец НЕ просил скрывать системную строку Apple: часы, заряд, Wi-Fi и системные пункты должны быть доступны в полноэкранном режиме. Старый расчёт 64–88px вырезан; используется состояние нативного меню/его фактическая высота. Public AppKit исключает HideMenuBar/DisableAppleMenu, оставляет обычную системную строку и пользовательские настройки; без kiosk, глобальных defaults и окон поверх меню. Пустая строка собственного браузера не добавляется. Нативные тесты обязательны; поведение личного выреза/настроек на M1 Pro не выдаётся за проверенное автоматически.

Правый ИИ: ровно одна компактная строка — favicon сервиса перед именем, добавление ссылки, обновление, закрытие. Отдельная строка «ИИ-чат» удалена. Иконки загружаются с самого сервиса/его текущей favicon, ограниченно и как инертные изображения. Сайты/контент чатов не перерисовываются и не брендируются нашей мышью.

Публикация только Mac Mouse Browser из OSMINOG / OSMINOG-Releases. Канал с историческим quadro tag и проверенной alias-ссылкой сохраняется для обновления с6.0.5; primary DMG именуется Mouse-Browser. Без изменения других платформ и АвтоЦены. Ребрендинг не равен независимому аудиту кошелька: только Sepolia, как прежде. Подпись ad-hoc, не Developer ID/notarization. Домен не покупался и его доступность не подтверждена; выбранное владельцем имя не заменяется предположением о свободном домене.

Статус: изменения подготовлены; нативные проверки и публикация фиксируются ниже после фактического результата.
