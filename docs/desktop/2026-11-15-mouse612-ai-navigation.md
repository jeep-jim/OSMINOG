# Mouse Browser 6.0.12 — навигация ИИ и положение очков
Поручение владельца: в той же компактной строке ИИ добавить Назад/Вперёд; историю брать только у выбранной side-вкладки, включая входы/редиректы и переходы внутри страницы. Недоступные действия выключены; смена сервиса сохраняет отдельные истории. Не перезагружать и не перемещать основные окна.
Дополнительное поручение: сдвинуть только всю группу очков маскота на один пиксель влево по исходной сетке47×64. В обоих SVG применяется translate(-1 0), все пути/цвета/блики и тело мыши без изменений. Иконка кнопки очков и Dock не меняются.
Проверки: unit границ команд; настоящие клики по кнопкам в packaged Mac, redirect и pushState, переключение ИИ, основные окна неизменны, панель240px обеих тем, сохранение истории при закрытии панели. Прежние проверки приватности/профиля и переход6.0.11→6.0.12 сохраняются. Публикация только после успешных проверок и точных хэшей; ad-hoc, без Developer ID/нотариализации.

## Срочное дополнение: сообщение владельца о вылете
Выпуск остановлен до дополнительных проверок. На старом BrowserWorkspace воспроизведены два необработанных исключения Object has been destroyed: state после уничтожения WebContents и поздний did-stop-loading после dispose. Исправлены проверки живого объекта, поздние события, освобождение обработчиков и обращения библиотеки/overlay к закрытым страницам. При сбое renderer оболочки восстанавливается только локальный интерфейс, сохраняются существующие native-вкладки и изолированная память инкогнито; максимум2 попытки/минуту, без глобального подавления uncaughtException. Добавлен локальный ограниченный журнал кодов/типов без URL/сообщений/паролей, приватные события не пишутся. Точная связь с вылетом личного Mac без системного crash-report пока не подтверждена. Требуются принудительный renderer crash, восстановление обычного/приватного режима, закрытие страниц во время загрузки и fullscreen stress в настоящем DMG.
