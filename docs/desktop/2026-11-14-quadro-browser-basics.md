# Quadro 6.0.3 — обычные функции браузера и уточнение интерфейса

Прямое поручение владельца: разнести footer на левый/правый блок; зелёная кнопка — полноценный native fullscreen; убрать искусственный пустой отступ сверху; исправить крестик скриншота и убрать ошибающийся «Экран Mac»; адресные подсказки, сохранение запросов, история, удобные загрузки. Иконку, профиль и остальные проекты не менять.

В подготовленном коде: постоянные точки сохраняются, зелёная включает/выключает fullscreen, фиксированный fullscreen inset=0. Правая группа ИИ/кошелёк/обновление/полный экран/выход прижата вправо; слева прежние имя/язык/тема/настройки/камера/раскладка и новые история/закладки/загрузки.

Крестик скриншота закрывает только редактор, Esc сначала закрывает модальное окно, не fullscreen. У открытых диалогов отключён draggable region под кнопкой. Кнопка «Экран Mac» из редактора удалена; региональный снимок браузера и все инструменты разметки сохранены. Новая проверка нажимает крестик настоящим mouse event, не DOM click().

История/запросы/закладки/последние закрытые вкладки/список загрузок хранятся локально в новом ключе существующего профиля. Записи начинаются с этой версии: предыдущая история не выдумывается. Подсказки из локальных данных, без внешнего suggestion API; popup клиппирует native page, не перезагружает и не уменьшает документ. Лимиты: история5000, запросы500, закладки1000, закрытые30, загрузки300. История с поиском, датами и удалением; очистка списка требует подтверждение. Закладка — звезда/⌘D, вернуть закрытую — ⌘⇧T.

Загрузки: стандартный выбор пути, прогресс, pause/resume пока DownloadItem жив, отмена/повтор, открытие с подтверждением и Finder. Удаление записи не удаляет файл. После перезапуска незавершённые записи помечаются прерванными, не имитируется resume без серверного состояния. Парольный менеджер, синхронизация и совместимость с любым расширением не заявляются. Это конкретный набор базовых функций, не весь Safari/Chrome.

Проверки: unit + native packaged arm64, реальные адресные события, history/bookmarks/suggestions popup, download fixture на localhost с реальным файлом/pause/resume, фактический X в обычном/fullscreen режиме, сохранение библиотеки и старого профиля. Старые тесты drag/AI/favicon/разметки/контраста/закрытия сохранены. На этапе записи исходники подготовлены, успех CI/публикации ещё не подтверждён. Ad-hoc подпись без Apple notarization/Developer ID; замена приложения из DMG ручная.
