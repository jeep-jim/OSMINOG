# Mouse Browser6.0.9 — выполнение поручения

Владелец сообщил повторный userDeclined при уже включённом разрешении, попросил крупный логотип в обновлении, временные цифры размеров при перетягивании и убрать нативную полосу поверх вкладок, не меню Apple.

В6.0.8 nativeCapture вытеснил прежний desktopCapturer наmacOS14+. Восстановлен прежний путь при действующем разрешении. Ограниченная последовательность legacy -> native direct -> explicit picker, без повторения после отмены. Picker-filter используется одним SCStream до первого complete-frame, остановка до возврата PNG. Нет аудио/фоновой записи/внешней отправки. Ошибки сохраняют nativeDomain/nativeCode, текст не обвиняет владельца в нажатии «Отказать». Никаких сбросов TCC или отключения защиты. Ad-hoc-подпись меняется между сборками, это остаётся отдельным ограничением.

Диалог обновления использует исходную мышь144x144 и реальный phase/progress, учитывает reduced-motion. Размеры панелей вычисляются из текущей геометрии, центрированы, видны только при реальном изменении drag и не сохраняются.

Отдельная AppKit-titlebar убирается только через view/window, связанные со стандартными кнопками текущего окна. Не снимается Titled style (Electron добавляет его для стабильности), не меняется системное меню, часы/Apple/Wi-Fi остаются доступны. Нужен нативный снимок и CGEvent click для проверки, одного DOM-теста недостаточно.

Новые локальные проверки и прежние регрессии обязательны. Публикация только после Mac runtime/DMG/обновления608->609 и обратной сверки SHA256 статического канала. Фавиконкиissue138 вне этого патча, приватность/кошелёк/другие платформы/АвтоЦена не меняются.
