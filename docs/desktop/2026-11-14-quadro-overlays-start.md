# Quadro 6.0.4 — меню поверх страниц и визуальная новая вкладка

Прямое сообщение владельца: нижние меню оказываются «в фоне», кликается только активный сайт. Дополнение с примером Safari: приблизить новую вкладку к стилю Mac, красивые визуальные закладки/недавние сайты/настраиваемый фон (задача #134). Прежние иконку, название, профили и раскладки не менять.

Исправление: DOM dialog сам по себе не располагается поверх native WebContentsView. Прежний вызов layout([]) разовый и не защищён от запоздавшего layout. Добавлен отдельный Mac host-side OverlayGate: до открытия модального окна временно скрывает и отсоединяет только native поверхности, сохраняет их webContents/сессии, отвергает их возврат при любых layout/resize до закрытия последнего диалога. Упорядоченные номера IPC отклоняют запоздавшие состояния. Все диалоги (настройки, библиотека, кошелёк, обновление, камера, стартовая страница) используют одну блокировку. Язык/число окон/ИИ открывают компактный доступный chooser через тот же механизм. Закрытие восстанавливает страницы без навигации или потери форм. Требуется нативная проверка видимости/parent-child, а не только DOM click(), который обходит проблему перекрытия.

Новая вкладка — локальная страница: системный шрифт, аккуратные округлые плитки, сдержанные стеклянные поверхности, встроенные градиентные фоны и выбор собственного PNG/JPEG/WebP. Пользовательские изображения не загружаются в сеть; копия с ограничением размера хранится в прежнем профиле. Избранное можно добавлять/редактировать/удалять; прежний лимит1000 снят, пагинация не ограничивает коллекцию и не удаляет старые записи. Недавние сайты только из реальной локальной истории, без выдуманных посещений. Внутренние вкладки хранятся отдельно и не получают прав привилегированных сторонних страниц. Добавления/фон/вкладки сохраняются при перезапуске. Плитка открывает сайт в выбранном окне. Новая вкладка доступна через + и Cmd+T, также в свободных плитках. Фоны-пресеты — градиенты, не фотография из примера владельца. Favicon запрашиваются у самих сайтов ограниченными запросами; сторонние сервисы иконок не подключаются.

План проверки: 22 unit-теста включая коллекцию1305 закладок и искусственно запоздавший layout; затем упакованный arm64 Mac, все нижние модальные меню, реальный mouse input, отсутствие native дочерних поверхностей над меню, раскрытие select, новая вкладка/закладка/фактическая навигация/недавние/свой фон/перезапуск. Все прежние регрессии скриншотов, сохранения, закрытия и раскладок остаются. Пока сборка/публикация не подтверждены; точные результаты дополняются отдельно.

Работа только OSMINOG/OSMINOG-Releases, Mac Quadro. Windows/Chrome/Android/АвтоЦена не меняются. Подпись ad-hoc, не Developer ID; Apple notarization отсутствует. DMG заменяется вручную; ошибка анонимного GitHub update discovery в6.0.3 не считается исправленной без проверки.
