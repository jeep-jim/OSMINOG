# Mouse Browser 6.0.16 — проверка перед публикацией

Поручение владельца: постоянный плюс в норке; единый стиль трёх нижних кнопок без смены их позиции; перезагрузка ИИ слева; удалить звезду и две кнопки деления из шапки панели; отклик перезагрузки; направление стрелок по реальному fullscreen; скруглить только внутренние горизонтальные стыки центральных окон; удалить экспериментальный кошелёк.

Функции закладок/деления остаются в меню и нижней панели. Удалены только их отмеченные дубликаты в шапках. Экспериментальный Mac-кошелёк, его IPC, внедряемый провайдер и отдельные зависимости удалены из приложения. Пользовательские файлы кошелька, профиль, cookies и ключи совместимости не удаляются.

Локальные проверки: 86 целевых тестов, обе темы, ширины 800/1100/1440. В первой нативной проверке исправлен тест анимации: macOS включает уменьшение движения, поэтому допускается предусмотренный неподвижный индикатор. Настоящие запросы перезагрузки удерживаются локальным HTTP-стендом до проверки loading/aria-busy; тест не зависит от времени сети.

Вторая нативная проверка выявила настоящий дефект: общий Electron View скругляет оболочку, но не маскирует Cocoa-веб-страницу. Заменено на точную маску принадлежащих окну нативных веб-представлений. Размер страницы и координаты событий не меняются, ИИ/внешние края не затрагиваются. Ключи сохранённых масок слабые, нет удержания уничтоженных NSView. Реальная проверка пикселей скриншота остаётся обязательной. Защита macOS и разрешения не меняются.

Выпуск ещё не опубликован. Публиковать только после успешной нативной сборки, проверки готового DMG и настоящего обновления 6.0.15 → 6.0.16 с сохранением профиля. Проверки ранних неуспешных кандидатов не считаются готовым выпуском. АвтоЦена и другие платформы не публикуются.
