Владелец сообщил, что установленная 6.0.34 вместо поиска показывает `Error invoking remote method 'mouse:tile-search': SearchError: Не удалось подключиться к серверу.` На приложенном экране запрос «новости про антропик», пустая выдача, справа прежний поиск/ИИ. Также сообщено мерцание файлов в «Скачанных» и «Скриншотах». Нужны исправление работающего поиска и переделка интерфейса, без мелких капс-заголовков и шаблонных рекламных блоков.

Исходные вложения: `3_deepseek_markdown_20261121_9b2bf8.md`, SHA-256 `890a9d0d2b9eebee4eb8e471485bd6bfb13399e003151136c2b0963628908c9b`; `image(20261121-045308).png`, SHA-256 `28460f2bd5cdce4e21c7d1a80d10742084754b504b8c7b0a3c2c2bff6f86b8b2`.

Новое ТЗ явно заменяет часть 6.0.34: «Показать экран» удаляется из поиска и остаётся в Agent Mouse; поиск получает фон браузера, фиолетовый акцент без зелёных кнопок, скругление плиток 16px, видимое состояние загрузки. Сохраняются живые сайты слева, поиск/чат справа, Open Graph-данные и временное пространство с восстановлением исходного стола. Пользователь не должен ставить Docker или запускать локальный сервер.

## Первичная проверка

- Утверждение приложенного ТЗ о localhost:8080 не подтверждено исходниками выпущенной версии: фактический default endpoint — внешний HTTPS `151.248.113.177:3082/search`, ИИ — порт3081; bundled CA входит в пакет. Историческая причина ошибки на устройстве владельца пока не установлена.
- Текущий `requestBuffer` использует Node HTTPS и сворачивает сетевые исключения в общий текст. Отдельная успешная Node-проверка 6.0.34 не доказывала работу публичного запроса через установленный Electron. Нужна обязательная проверка production пути из собранного приложения.
- `desktop/mouse/browsing.js` при событии списка полностью пересоздаёт строки через `replaceChildren`, сбрасывает observer и повторно получает previews. Общие события приходят в том числе при progress/history/favicon; это конкретный механизм повторной отрисовки и утраты уже созданных миниатюр. Исправление и before/after проверка ещё выполняются.

## Обязательная приёмка

1. Реальные публичные запросы из установленного Electron через production transport, с проверкой ссылок, pagination и честной обработкой отказа; fixtures не выдаются за внешний поиск. Никаких API-ключей в клиенте, отключения TLS или обхода CAPTCHA/429.
2. Обе темы и реальная native геометрия новой выдачи; отсутствие блока «Показать экран» в поиске; сохранение ограничений живых страниц и восстановления стола.
3. Стабильные DOM-узлы строк и миниатюр при progress/cross-section updates, сохранение scroll/selection/preview; реальные изменения и удаления по-прежнему отражаются.
4. Сохранение прежних native/profile/privacy/обновляторных проверок и фактическое обновление опубликованной 6.0.34 до нового пакета. Публикация признаётся завершённой только после проверки пакетов и каналов.

История 6.0.34 сохраняется: её прежние CI-результаты не стираются и не отменяют новый фактический отказ владельца. Инфраструктура АвтоЦены не используется.

## Уточнение владельца: только публичные API

Последнее прямое требование заменяет прежний план провайдеров: Main-процесс использует публичный API поиска (DuckDuckGo Instant Answer / Brave Search API) с переходом на следующий API при отказе. Локальные серверы, Docker, собственный SearXNG по умолчанию и HTML-парсинг поисковой выдачи исключены. Open Graph отдельных найденных страниц остаётся. ИИ по найденным результатам — отдельная существующая функция, не источник выдуманных ссылок.

Подготовленный путь: настроенный Brave запускается первым; DuckDuckGo Instant Answer — отдельная справка с явным источником; Mwmbl JSON — ограниченный резерв. Разбиение одного ответа Mwmbl на страницы обозначается как snapshot, а не как поддерживаемая сервером пагинация. Ограничения покрытия нельзя скрывать одинаковыми заголовками или успехом другого запроса. Общий ключ не встраивается в пакет. Личный ключ Brave вводится в настройках поиска и хранится только с помощью доступного защищённого хранилища ОС; незашифрованный fallback запрещён. Для native CI допускается только краткоживущая передача repository secret BRAVE_SEARCH_API_KEY в MOUSE_TEST_BRAVE_SEARCH_API_KEY на шаге запуска установленного кандидата, не на шаге сборки.
