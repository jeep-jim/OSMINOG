# Mouse Browser 6.0.8 — прямое поручение владельца

Пять требований: белый маскот инкогнито с квадратными пикселями/усами и неизменными чёрными очками; постоянная чёрная мышь на белом в Dock; реальный снимок Mac после разрешения; разворачивание каждой панели с возвратом на исходное место; обновление из приложения.

Текущий кандидат: исходная22x30 маска равномерно удваивается (каждая клетка2x2), вместо искажающего пересчёта в47x64. Очки остаются на своей целочисленной сетке. Dock не следует теме. Focus панели не сериализуется и не меняет дерево раскладки; Esc/native exit возвращают исходные страницы без reload. Стандартный full-screen до входа сохраняется.

Захват: отдельный N-API модуль ScreenCaptureKit в том же процессе, один PNG без аудио/потока/записи на диск. На macOS14+ при отсутствии действующего разрешения используется настоящий SCContentSharingPicker: человек явно выбирает экран и разрешает один захват. На macOS13 остаётся предыдущая проверка TCC с указанием точной категории разрешения. Никаких tccutil/defaults, смены прав или обхода запрета. Устройство владельца и причина его отказа ещё не диагностированы; не объявлять их исправленными по статическому тесту.

Обновление: основной HTTPS JSON в OSMINOG-Releases/main/channels/mouse/macos-arm64.json, API только резерв. URL/архитектура/версия/размер/SHA256 валидируются; сообщение «актуально» только после успешного чтения. Перед заменой повторный hash, readonly DMG, arm64/bundleID/version/codesign, staging рядом с приложением; непривилегированный helper ждёт закрытия, делает замену и сохраняет previous.app. Профиль не удаляется; никаких xattr/spctl/sudo. DeveloperID/нотариализации всё ещё нет. Установленную6.0.7 нельзя исправить удалённо: для перехода на новый механизм потребуется установить6.0.8, последующие выпуски поддерживаются новой кнопкой. Канал публикуется только после реального выпуска и сверки asset hash.

Локально31 targeted+19 legacy прошли. Нативный build/ScreenCaptureKit/pane geometry/installer проверяются отдельно. System title strip и faviconissue138 не входят в этот патч и не закрываются. Другие платформы и АвтоЦена вне задачи. Существующие профиль/appId/partitions сохранены.
