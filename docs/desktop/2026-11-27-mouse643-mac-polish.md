# Mouse Browser 6.0.43 — Mac: поиск, панели и темы

## Прямое решение владельца

27 ноября 2026, KRAT (UTC+7): до отдельной команды владельца дальнейшая разработка и публикация Mouse выполняются **только для macOS Apple Silicon**. Windows и Linux поставлены на паузу; их опубликованные 6.0.42, пакеты и каналы остаются доступными. Перенос накопленных изменений на остальные ОС — только после нового поручения. Сайт меняется при необходимости; эта задача не затрагивает АвтоЦену.

## Задание

Следующая версия после опубликованной 6.0.42:

- Чёрный знак Mouse на обычной новой вкладке в обеих темах. Компактный поиск с иконкой выбранного поисковика слева, сменой по нажатию и выпадающими подсказками.
- Активная верхняя вкладка совпадает с фоном. Стабильная геометрия при обновлении заголовка и перетаскивании; прямоугольная сетка получает прямоугольные вкладки.
- Пользовательский цвет панелей сохраняет форму «норки», семантические цвета кнопок окна и аккуратный вид малых кнопок.
- При редактировании адреса — кнопка копирования справа; рядом с фавиконкой — стрелка списка открытых страниц всех столов и недавних посещений с фавиконками.
- Более плоское оформление Настроек, обычный регистр заголовков и отступы у стрелок.
- Тема Chromium синхронизируется с темой Mouse, в том числе до восстановления сохранённых страниц и при возвращении из инкогнито. Проверяется реальный `prefers-color-scheme`, а не только цвет оболочки. Явная собственная настройка темы сайта может иметь приоритет над системным предпочтением; произвольные стили, cookies и настройки аккаунта сайта не подменяются.

## Исходная точка и найденные причины

Начальная точка: `495ea9e75e4ca6166b7c2fbafab3156d711a816a`. Перед отправкой сохранён более свежий docs-only main `9d5a781a7feea3de0b67fc6d49750ce779614bce`, включая новый журнал сайта и запись наблюдения в сводке. Предыдущая реализация642 принята на `ac51d80d4190bce54d8cc5f7017359dcb8fa838c`, [PR222](https://github.com/jeep-jim/OSMINOG/pull/222); [полная публикация642](2026-11-27-mouse642-navigation-grid.md).

В `appearance.css` пользовательская поверхность применяла фон ко всем вложенным кнопкам, включая traffic lights и «норку». Активная верхняя вкладка окрашивалась отдельной SVG-фигурой в `--line`; прямоугольный режим эту фигуру не отключал. В main `nativeTheme` уже переключался по IPC, но при запуске сначала принудительно выставлялся `light` до чтения сохранённой темы.

## Реализация кандидата

Mac-вкладка рисует собственный фон без второго SVG-слоя; заголовок не определяет ширину вкладки. Правила собственных цветов ограничены соответствующими компонентами. Стрелка списка адресов сохраняет отдельную область favicon для переноса; копирование сверяет адрес с актуальным WebContents текущего обычного/приватного пространства. Список объединяет открытые страницы всех столов и недавнюю историю, умеет локально фильтровать их и переключать существующую вкладку. На Mac временно резервируется настоящий viewport под DOM-popover; при закрытии возвращаются исходные границы тех же живых страниц. У нижних плиток список открывается вверх.

Обычные поисковые подсказки используют выбранный поисковик, задержку240мс, до8 строк и ограниченный HTTPS-ответ. В инкогнито сетевые подсказки отключены. Ошибка сервиса не мешает обычному поиску. Native643 проверяет настоящий HTTP на собственном loopback fixture через main-only test transport и честно записывает `externalProviderVerified:false`: этот тест не считается доказательством доступности внешнего поисковика.

Mac metadata643 включает новый `polish643` manifest. Windows/Linux workflows поставлены на явную паузу; их metadata остаётся642. Актуальный predecessor — опубликованный642, старый путь629 также сохраняется. Принятые642 исходники, пакеты и pins не переписываются.

## Проверка

До удалённой Mac-проверки: общий Mouse runner —1720 PASS,0 FAIL,11 платформенных SKIP;13 обязательных групп Python reader/upgrade tests также прошли. Отдельно проверены новый поиск, оформление, адреса и восстановление фактической native-геометрии после закрытия списка. Общий `npm test` локально дал177 PASS/5 FAIL: все5 отказов — `listen EPERM` в неизменённом `mcp-host.test.cjs` при создании Unix socket. Этот результат не помечается успешным; тот же обязательный шаг выполняется в Mac CI. BrowserWindow здесь не запускался: локальная Chromium runtime отсутствует. Реальные пиксели, native input и установленный пакет проверяет Mac CI.

План: поведение поиска и клавиатуры; реальные адресные действия и clipboard; открытые страницы разных столов без повторной загрузки; обе темы и собственные цвета панелей; геометрия вкладок, сетки и перетаскивания; сохранение предпочтений и возврат из инкогнито; установка и обновление из опубликованной642. Windows/Linux не собираются и не публикуются.
