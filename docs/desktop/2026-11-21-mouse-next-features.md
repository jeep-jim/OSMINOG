# Mouse: интерфейс, расширения и плеер

Кандидат поверх принятого 6.0.36. Не перезаписывает публичный канал 6.0.36 и не возвращает плиточный поиск.

- Языковое меню: 72 локали для будущих переводов, реально переключаются только русский и английский.
- Окна: скруглённая подсветка перетаскивания, более спокойный тёмный разделитель и адрес, шапка компактной панели открывается при наведении или фокусе.
- Расширения: только совместимые распакованные пакеты после согласия, только обычный профиль. Объявленная HTML-страница открывается в панели и меняет размер. Нет Web Store, запуска неизвестного формата и восстановления самой панели после перезапуска.
- Плеер: управляет исходной вкладкой без захвата звука. Полный на родном столе, полоска справа от Норки на других. Работа конкретно с VK пока не подтверждена.

Локально: 51 целевой тест на объединённом исходнике. Публичный выпуск требует установленной проверки на macOS, Windows и Linux, а также проверки расширения и плеера с контролируемыми тестовыми страницами. Обновляющий канал этим PR не меняется.
