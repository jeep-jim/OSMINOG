# Quadro 6.0.5 — Mac, боковая библиотека и Web3 preview

Поручение владельца: верхняя системная плашка перекрывает вкладки; чёрные favicon не видны в тёмной теме; избранное/загрузки справа как ИИ; разлипить кнопки настроек/обновления и единый умеренный glass; встроенный настоящий Web3-кошелёк. Иконку, имя, профиль и другие проекты не менять.

Интерфейс: временный отступ при касании верхней кромки в native fullscreen, с задержкой сворачивания для кликов по вкладкам. Не отключает системное меню и не меняет настройки macOS. Постоянной пустой полосы нет; M1 Pro notch и разные настройки меню требуют проверки владельцем. Боковая библиотека немодальная, своя изменяемая ширина; временно заменяет ИИ, возвращая его после закрытия. Обычные страницы остаются интерактивными. Настройки/подтверждения используют прежний OverlayGate. Монохромные favicon анализируются по пикселям, чёрные инвертируются в тёмной теме, цветные не инвертируются. Системный стиль: отступы между действиями, полупрозрачные кнопки, контрастный текст, обе темы.

Кошелёк: экспериментальный MVP, НЕ полная замена MetaMask для реальных средств. Только Sepolia chainId11155111. Создание случайного EVM ключа, зашифрованный JSON v3 ethers6.17.0, импорт такого JSON, обязательная резервная копия до подключения/подписи, автоблокировка5мин/lock-screen/suspend. EIP1193 request и EIP6963 discovery: разрешение сайта, personal_sign, chain-bound typed-data, transaction nonce/gas/RPC simulation/native review before signing and broadcasting. Mainnet/другие сети/eth_sign/raw signing/EIP7702 не включены. Ключ не передаётся в webview/ИИ; нет передачи seed в чат; сайт получает только разрешённый адрес/результат. Прежние публичные адреса сохранены отдельно. RPC HTTPS выбирает владелец, никаких скрытых RPC сервисов/платежей/отправок. Независимый аудит не пройден; реальные средства использовать нельзя. Проверка на локальном RPC и математическое восстановление подписей не считаются live on-chain транзакцией.

Библиотека криптографии изолирована от package.json других платформ, точная версия/lock/audit; bundle только в Quadro. Источники: https://eips.ethereum.org/EIPS/eip-1193 , https://eips.ethereum.org/EIPS/eip-6963 , https://docs.ethers.org/v6/api/wallet/ , https://www.electronjs.org/docs/latest/api/browser-window .

На этом этапе исходники подготовлены. Факт сборки, тестов, публикации и ограничения фиксируются после проверки. Подпись ad-hoc без Developer ID/notarization, замена DMG ручная. Старый профиль не удалять.


## Прямое дополнение владельца — глобальный скриншот Control+A

Владелец попросил вызывать скриншот не только в браузере, но в любом приложении Mac. В6.0.5 добавлен globalShortcut Control+A с регистрацией после ready, явной диагностикой конфликта и выключателем в настройках. Работает только пока Quadro запущен, включая фон/свёрнутое окно. Никакой отдельный скрытый агент, автозапуск без согласия или изменение поведения Cmd+Q не добавлены. При выходе сочетание освобождается. Cmd+A не переопределяется. Control+A займёт это сочетание в других приложениях; выключатель позволяет его освободить.

Один снимок дисплея под указателем выполняется по явному нажатию ДО появления отдельного редактора. Редактор — отдельное sandbox/context-isolated окно без доступа к браузеру, кошельку или произвольным файлам; только одноразовое получение изображения, copy/save PNG и close. На macOS требуется разрешение screen recording. При denied/restricted захват не выполняется, предлагаются настройки macOS; разрешение не обходится. Нет фоновой записи/аудио/стрима/передачи в облако. Esc/X закрывают только редактор, снимок очищается. Камера браузера сохраняет прежний локальный режим без системного разрешения.

Проверки:30 локальных unit-тестов прошли, включая регистрацию/конфликт/выключение/освобождение сочетания, отказ разрешения и порядок capture-before-UI. Нативная проверка должна отдельно подтвердить регистрацию OS hotkey, Ctrl+A из страницы, редактор при скрытом главном окне, регион/copy/PNG/X, изоляцию моста. Пиксели в этом тесте синтетические, помечены fixture. Реальный захват дисплея запускается в CI только при уже выданном системном TCC-разрешении; иначе записывается NOT_TESTED_TCC, не success. Физическое нажатие пользователем в сторонней программе/его раскладке клавиатуры и permission grant на M1 Pro пока не наблюдались.

Основание API: https://www.electronjs.org/docs/latest/api/global-shortcut/ , https://www.electronjs.org/docs/latest/api/desktop-capturer/ , https://www.electronjs.org/docs/latest/api/system-preferences . Реализация кошелька сверена с https://eips.ethereum.org/EIPS/eip-1193 , https://eips.ethereum.org/EIPS/eip-6963 и https://docs.ethers.org/v6/api/wallet/ . Это не независимый аудит кошелька.

На этой записи исходники подготовлены. Точные native run/source SHA, реальная публикация и оставшиеся ограничения фиксируются после проверки. Подготовленный код не выдаётся за установленный выпуск.
