# 2026-11-13 — Quadro 6.0.1: одна строка и завершение без чёрного Space

Прямое поручение владельца после установки 6.0.0: сохранить многооконный браузер, убрать 2–3 верхних ряда, сделать один компактный ряд в стиле macOS, показывать оконные кнопки слева при наведении без перекрытия, перенести настройки/обновление в тонкую нижнюю полоску, устранить чёрный экран после закрытия приложения.

Изменения: общая навигация/адрес выбранной страницы + вкладки в одной строке 46px. Постоянные панели адресов над каждой плиткой удалены; выбранная плитка отмечена рамкой, фокус страницы переключает общую строку. Закрытие вкладки слева появляется при hover/focus и занимает заранее отведённое место. Нативные traffic lights используют customButtonsOnHover и отдельную свободную зону 80px, не закрывающую вкладки. Нижняя полоска 28px: настройки/тема, раскладки, разделение справа/снизу, удаление плитки без удаления вкладки, ИИ, кошелёк, обновление, полный экран и завершение.

Предыдущий close-handler делал preventDefault + hide, в том числе в native fullscreen. Новый единый механизм для красной кнопки и Cmd+Q сохраняет pending renderer preferences, browser sessions и cookies, ждёт leave-full-screen и завершает приложение вместо hide. Ошибка сохранения оставляет видимое приложение открытым; повторный выход возможен. Таймаут fullscreen не приводит к бесконечному ожиданию. Esc выводит из полноэкранного режима даже при фокусе на веб-странице. Данные профиля и существующие страницы не удаляются.

Проверки: модульные сценарии close/CmdQ/fullscreen/error/retry; packaged Mac 1/2/4/6 окон и resize обоих направлений сохранены. Добавлены геометрия одной строки/нижних кнопок 1440/1100/900/800, общий адрес после фокуса страницы, native normal/fullscreen close и quit с фактическим завершением процесса и сохранением последнего изменения. CI не является просмотром экрана владельца. Статус этой записи: изменения подготовлены, build и публикация ещё не подтверждены.

Техническое основание: https://www.electronjs.org/docs/latest/tutorial/custom-title-bar (customButtonsOnHover); https://www.electronjs.org/docs/latest/api/base-window#setfullscreenflag (асинхронный leave-full-screen). customButtonsOnHover помечен Electron как experimental; итог проверять в упакованном Mac-приложении.

Работа только в OSMINOG/OSMINOG-Releases, без АвтоЦены/Windows/Chrome/Android. Mac appId и старый путь профиля сохраняются. Версия 6.0.1, отдельный Quadro update channel; подпись ad-hoc, без Developer ID/notarization.
