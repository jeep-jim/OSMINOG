# 13 ноября 2026 — Quadro Browser для Mac M1 Pro

Новое прямое решение владельца заменяет торговую концепцию desktop на Mac: имя **Quadro Browser**, универсальный многооконный браузер, без левой колонки и её кнопок, тикеров, watchlist, рынков, скальпинга и других торговых элементов. Сохранить существующий кошелёк и правую панель ИИ, принимать произвольную ссылку ИИ, позволить менять ширину чата и ширину/высоту окон. Исправить нечитаемые кнопки светлой темы и огромный значок в верхней строке меню macOS. АвтоЦену внутри страницы и другие проекты не редактировать.

Реализация изолирована в desktop/quadro*, новый macOS entry point и собственный workflow. Windows/Chrome/Android исходники и каналы выпуска не меняются. Старое имя профиля и project ID сохранены только внутренне ради вкладок/cookies/публичных адресов. История roadmap и старые исходники не удаляются. В новом приложении не создаётся Tray/status-item.

Окна организованы в сохраняемое дерево разделений (до 12), есть готовые раскладки, разделение справа/снизу, перетаскивание вертикальных и горизонтальных разделителей, клавиатурное изменение и сброс двойным щелчком. На время drag native views скрываются, затем их границы синхронизируются без reload и замены webContents. Закрытие ИИ освобождает всю ширину от левого до правого края. ИИ по URL — обычная sandboxed страница; автоматическая передача контекста/ключей/паролей и торговый AI executor не подключаются.

Кошелёк в прежнем коде является watch-only хранилищем публичных EVM-адресов, не MetaMask и не подписывающим кошельком. Этот факт явно указан в новом интерфейсе; seed/private keys не принимаются. Сохранение функции не означает готовность транзакций.

Обновление: опубликованная 5.0.3 содержит ManualMacUpdates, отклоняющий check/download/install. Дистанционно изменить этот установленный код нельзя; первый переход требует нового DMG. В Quadro добавлены проверка отдельного канала, загрузка DMG с контролем размера/SHA-256 и открытие установщика по кнопке. Автоматическая замена приложения не имитируется. Подпись ad-hoc, Developer ID/notarization не настроены; защиту macOS не отключать. Иконка установочного диска на рабочем столе — смонтированный пользователем DMG; его извлечение не выдаётся за действие на его Mac.

Тестовый план: реальные packaged arm64 окна, 1/2/4/6 layouts на разных размерах, pointer-driven drag обоих направлений, custom AI URL и ширина, hide/show без reload, контраст обеих тем, сохранение layout/cookies/адресов, обычный запуск. Синтетические fixtures явно тестовые, не подтверждают авторизацию в личных аккаунтах или полноценный upgrade со старым приложением. В этом коммите сборка и публикация ещё не подтверждены; результаты добавляются после фактического завершения.
