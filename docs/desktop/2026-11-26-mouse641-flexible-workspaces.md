# Mouse 6.0.41 — вкладки, сетка и оформление

## Статус

Реализация начата от свежего `main` — `85fa6dc6128c24016a97bc96c68022d159914da4`. 6.0.40 опубликована и остаётся проверенным предшественником. Новый выпуск ещё не принят и не опубликован. Порядок по поручению владельца: Mac → Linux → Windows.

## Прямое поручение владельца

- Исключения AdBlock для отдельных сайтов: checkbox в контекстном меню страницы; список в настройках; добавление адресом или выбором открытой вкладки.
- Просмотр верхней вкладки и открытой ссылки на одной странице с явным возвратом к сохранённой сетке. Просмотр не заменяет плитку и не меняет её размер/положение.
- Новая плитка открывает стартовую страницу с поиском, избранным и выбором существующих вкладок.
- Перенос за свободную область сайта, перенос между столами удержанием у края, вставка между плитками с видимой подсказкой. Сохраняются реальные живые страницы, формы, сессии и звук.
- Отдельные цвета/градиенты верхней панели, нижней панели, пространства между плитками; отдельная прозрачность панелей; независимое сохранение светлой и тёмной темы.
- История, загрузки и остальные библиотечные поверхности используют общий стеклянный стиль настроек.
- Шапка каждой плитки всегда видима, включая минимальный размер.
- Нижний плеер полностью удаляется вместе с его IPC/опросом. Музыка на сайтах и управление звуком вкладки остаются.

## Границы реализации

Профиль, partition, App ID, cookies, адреса обновления и старые опубликованные пакеты сохраняются. Новые взаимодействия страниц проходят из изолированного preload через проверку живого WebContents; страница не получает API управления браузером. Частный режим не записывает URL/исключения в постоянный профиль. Закреплённые плитки продолжают защищать вкладку, положение и размер. Agent Mouse и отменённый плиточный поиск не возвращаются.

Просмотр одной страницы хранится отдельно от `tree`/`slots`; возврат восстанавливает ту же сетку. Изменение сетки выполняется явным действием размещения, разделения или перетаскивания. Перенос между столами не меняет владельца страницы до подтверждённого drop.
