# Mouse 6.0.34 — собственный визуальный поиск

## Дополнение владельца20.11.2026

Владелец во время завершения634 прямо добавил в эту же общую Mac/Windows/Linux сборку собственный поиск. На нижней панели лупа находится непосредственно слева от существующего смайлика. Справа открывается собственная поисковая/ИИ-панель с маскотом Mouse над строкой поиска, слева — прокручиваемая masonry-выдача с действительно открытыми сайтами. Прежний рабочий стол сохраняется и возвращается после закрытия поиска.

Основание: прямое сообщение владельца и два приложенных ТЗ `searsh_deepseek_markdown_20261120_75d84f.md`, `1_2_deepseek_markdown_20261120_948a3f.md`. Первое задаёт SearXNG JSON, Open Graph, классификацию видео/товар/статья, фильтры, пагинацию и краткий ИИ-ответ. Второе добавляет явно включаемый режим «Показать экран»: структурированный контекст выбранной страницы и реальные клики с виртуальным трекпадом. Переданный второй текст заканчивается на примере JSON; отсутствующие продолжения не считаются требованиями. Прямое уточнение о живых сайтах обновляет предложение статичных OG-превью: результаты — отдельные sandboxed WebContentsView, а метаданные остаются подписью/типом/ценой.

## Реализация и границы

- Собственная точка поиска — выделенный SearXNG сервис в `/opt/osminog/mouse-search` под существующим пользователем osminog. Это метапоиск через собственный сервис; новый самостоятельный веб-индекс этим выпуском не создаётся. HTTPS3082, точный upstream commit, лимиты512MiB/25%CPU/64tasks, лимиты соединений/запросов, без изменения DNS/nginx/root или сервисов АвтоЦены. Деплой только из OSMINOG через его собственный доступ.
- Main-process выполняет реальный JSON-запрос, ограниченные запросы Open Graph, классификацию, дедупликацию, отмену и проверку URL/redirect/DNS. Renderer не получает полномочий менять endpoint/CA/секреты.
- ИИ использует существующий собственный REG gateway3081. Секрет модели остаётся на сервере. Нативная анонимная сессия хранится только с доступным системным шифрованием; без него остаётся в RAM. Summary по первой странице и явные сообщения используют реальные найденные данные; ошибки не заменяются придуманным ответом.
- Живые плитки имеют собственную временную Chromium-session, не добавляются в сохраняемые вкладки/столы и ограничены8 одновременно видимыми native pages. Прокрутка с гостевой страницы доставляется в masonry; невидимые страницы освобождаются. Открытие результата обычной вкладкой — отдельная явная команда.
- «Показать экран» включается пользователем только для выбранной видимой страницы. Изолированный observer читает роли/названия видимых элементов и trusted click, без скриншотов, значений полей, сырого ввода клавиатуры, cookies/clipboard/storage. Не открывается новый9222 и не захватывается debugger другой задачи. Навигация, закрытие, смена поиска, приватность и блокировка экрана снимают наблюдение.
- Поиск — временная отдельная поверхность. Capture/Nora/modal должны скрывать native cards за тем же барьером и возвращать их после закрытия; снимки используют фактические native layers. Прежние634 правки загрузок/скруглений/ИИ-preview и новая Нора не отменены.
