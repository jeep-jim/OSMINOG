## Все три поручения в одной сборке

Смайлик перед историей открывает системную панель эмодзи macOS через доверенный IPC и возвращает фокус в последнее доступное поле страницы, ИИ или оболочки. Приватное пространство обрабатывается отдельно. Windows-ветка API подготовлена и проверена модульными тестами; этот выпуск не содержит Windows-приложение. Системные недавние эмодзи принадлежат ОС, инкогнито браузера их не очищает.

Активная вкладка плавно соединяется с разделительной полосой: неинтерактивный SVG-фон использует тот же `var(--line)`, нижние сопряжения10px ограничиваются шириной сверхузких вкладок. Обводка норки также использует цвет полосы. Прежние обработчики вкладок, норка36×29px, её градиент, исходная маленькая голова и серый плюс12px сохранены. Фон синхронизируется с активной вкладкой, её фактическим размером, плотностью и прокруткой полосы.

История и закладки показывают реальные сохранённые favicon сайтов; для старых записей используется доступная иконка сайта. Иконки загружаются по видимости через очередь с ограничениями, без стороннего favicon-сервиса. Известные завершённые загрузки получают штатные иконки файлов ОС. Для отсутствующей/недоступной иконки остаётся нейтральный значок. Произвольные пути файлов через IPC не принимаются.

В библиотеке есть список/плитка, один верхний ряд управления без повторного видимого заголовка, «Показать все» рядом со счётчиком, checkbox выделения всего справа и появляющаяся «Очистить» слева. Удаление отдельной записи круглое. Длинные адреса ограничены карточками, горизонтального переполнения нет в проверенных режимах.

Выделение всего охватывает весь результат поиска, включая строки за пределами первых100; отдельные строки можно исключить. Перед подтверждением фиксируются точные ID: новые записи после открытия подтверждения не удаляются. Очистка удаляет только записи списка, не файлы на диске/cookies/пароли. Активные загрузки сохраняются. Большие внутренние snapshots обрабатываются партиями без ослабления валидации входящих IPC-списков.
