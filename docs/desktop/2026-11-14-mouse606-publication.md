## Что входит

Точное имя Mouse Browser и исходная пользовательская пиксельная мышь вместо крестика. Мышь — маскот без личного имени. Чёрный/белый UI следует теме браузера, Dock запущенного приложения — теме macOS. ИИ имеет одну компактную строку с иконкой перед названием сервиса. Исправлены контраст стрелки поиска/меню плиток и обратная связь скриншота: короткая вспышка и «Снимок готов» после успешного получения изображения, без эффекта внутри PNG.

Инкогнито переключает текущее окно кнопкой очков или Cmd+Shift+N. Новая вкладка содержит маскот с пиксельными очками. Непостоянная Chromium session/cache:false и MemoryStore изолируют данные от обычного профиля. При выходе приватные страницы/данные очищаются, обычные страницы восстанавливаются без перезагрузки. Это не анонимность и не обещание физического стирания RAM/swap/системных журналов. Явно сохранённые файлы, скриншоты и буфер обмена остаются. Кошелёк в приватном режиме отключён.

Исправлена потеря нормального режима Mac-приложения после системного скриншота, приводившая к недоступности настоящего меню Apple. Доступность меню подтверждена нативным состоянием и снимком. Отсутствие дополнительной полосы не подтверждено — см. незакрытые дефекты ниже.

## Установка владельцу

Полностью завершить Quadro/Mouse через Cmd+Q. Скачать основной Mouse DMG, скопировать Mouse Browser.app в «Программы» и открыть именно Mouse Browser из «Программ». Из-за другого имени файла он не заменяет Quadro Browser.app автоматически. Старый .app можно удалить отдельно после проверки. Не запускать старый и новый одновременно. **Не удалять `~/Library/Application Support/Trader OS`** — это сохранённый профиль.

Нативная сборка для Apple Silicon/M1 Pro, macOS13+. Подпись ad-hoc, Developer ID/notarization отсутствуют; замена приложения ручная. Глобальный Control+A требует запущенного приложения и разрешения macOS на запись экрана, после переименования разрешение стоит проверить. Wallet остаётся Sepolia-only, неаудированным и не для реальных средств. Публикации других платформ/АвтоЦены не выполнялись.
