# Vision 0.2.7 — исправления по локальному макету

Источник: Untitled (3).fig, 867 декодированных узлов; SHA и извлечённые пути зафиксированы в assets/design/latest-local-design.json. Работа ведётся только в OSMINOG и его собственном release-репозитории.

- Исходный красный глаз восстановлен из 14305342; прежний синий квадрат не используется. Application ID/alias/origin не изменены.
- Inter поставляется локально с SIL OFL. Иконки четырёх настроек и общая стрелка — геометрия локального файла. Убраны рамки текстовых полей и touch-focus рамка кнопок; клавиатурный фокус сохранён.
- Выбор персонажа: кольцевая горизонтальная прокрутка с фиксацией по центру. Нажатие центрального персонажа выбирает фото. Язык раскрывается вниз в текущем меню, Back сворачивает его первым.
- До десяти смешанных вложений: оригинальные Blob в IndexedDB, без ограничения 2 МБ. Системная квота/свободная память остаются физическим пределом. Чат содержит только небольшие ссылки на локальные объекты. Просмотр фото/видео; ссылки открываются внешним браузером после проверки HTTP(S). Непросматриваемые типы файлов сохраняются локально и показывают имя; универсальный системный экспорт файлов пока не реализован.
- Океан доступен по компасу: личные явные намерения, фон-панорама с инерцией, pinch/wheel zoom, независимое перемещение мысли, глубина/размытие/скрытие вне экрана. Удержание мысли требует подтверждения перед удалением записи/ответов/локальных вложений и показывает лопание.
- Превью раскрывается перетягиванием ручки. Кнопка комментария сохраняет ответ на устройстве; отдельные черновики не смешиваются с личным чатом. Пузырики отражают реальные локальные комментарии, фото — только имеющийся аватар участника. Посторонние читатели/люди/счётчики не имитируются.
- Общий океан, peer discovery/media transfer и ИИ не подключены. Сохранение локального намерения/ответа не выдаётся за сетевую отправку; автоматической публикации после будущего подключения нет. Серверное хранение содержимого не добавлялось.
