# Vision 0.2.8 — голосовой ввод и локальные комментарии

Статус: RELEASED — 0.2.8 доступна через штатную кнопку обновления.

## Исправления

В 0.2.7 `startVoice` безусловно отклонял Android ниже 12 и телефоны без on-device speech service. Обычный системный распознаватель не использовался. Завершение записи вызывало cancel/destroy, поэтому финальный результат мог быть потерян.

Новый VoiceInput предпочитает локальный распознаватель. При отсутствии сервиса или языковой модели предлагает системный Android-сервис с отдельным согласием на текущую запись: провайдер этого сервиса может обрабатывать звук вне телефона. Без согласия системная запись не запускается. Системный режим после согласия не требует наличия офлайн-модели. При отсутствии обоих сервисов приложение объясняет причину; собственного акустического движка в APK нет.

Нажатие глаза при пустом поле начинает диктовку. Для непустого черновика: пузырь вложений → «Голосовой ввод». Повторное нажатие глаза завершает запись через stopListening и ждёт финальный результат. Уход в меню, океан или фон отменяет запись и освобождает сервис. Поколения callbacks и ID сессий отсекают запоздавший результат. Таймауты ограничивают зависший запуск/ответ. Разрешение микрофона обрабатывается с учётом pause/resume Android.

Распознанный текст добавляется к текущему черновику, сохраняется локально и не отправляется автоматически. Повторный результат не дублируется. Ошибки микрофона, занятого сервиса, сети и языковой модели различаются.

Комментарии на устройстве теперь редактируются и удаляются через кнопку действий; удаление подтверждается, счётчик и активность пузыря пересчитываются. Исправлены распознавание массива фото в метаданных личного сообщения и создание намерения только с файлом, без текста.

- 40 прежних Android/WebView тестов, 5 новых UI-сценариев и 8 контрактных тестов speech-service. Контрактные тесты используют fake engine: это не проверка реального микрофона, качества речи или конкретного сервиса на телефоне владельца.
- CI 42493244827, source 223690eafbe3a9d79bb67d7dd53682794d9f43e9: 53/53, build/lint/cold launch успешны. Artifact 13622677047, ZIP SHA-256 90d243be571e3a67f50a59519d36360711aaff05ab38b9b2b41b4c3917078dc2 проверен при скачивании.
- Снимок голосового согласия просмотрен. Снимок редактора комментария поймал предыдущий кадр; logcat показывает задержки compositor. Добавлено postVisualStateCallback перед снимками и проверка геометрии окна, а не ослабление проверок приложения. Прогон f68eaa130e050461af07dd585c26c8846ebb3ba5 также прошёл 53/53, но кадр compositor запаздывал после callback. Добавлены invalidate и выдержка 3 секунды только в screenshot helper тестового APK; код приложения не менялся. Финальный снимок показывает редактор комментария, текст и все три действия; просмотрен.
- Первоначальный lint выявил недостающий явный API guard вокруг фабрики локального распознавателя; исправлено без повышения minSdk и отключения lint.
- Исходные ресурсы/логотип и локальные файлы дизайна не менялись. Сохраняются package com.osminog.vision, прежний signer, локальный origin и ключи хранилища.
- ИИ, общий океан и обмен между устройствами не подключены. Локальные ответы не выдаются за сетевую публикацию. Полная концепция распределённого хранения/отзыва требует собственного транспорта и доступа к серверу.

Android API: https://developer.android.com/reference/android/speech/SpeechRecognizer — различие cancel/stopListening, требование main thread, destroy и возможная обработка системным сервисом на удалённом сервере.
