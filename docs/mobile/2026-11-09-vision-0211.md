# Vision 0.2.11 — новый локальный макет, персонаж и подключение REG

Источник: прямое поручение владельца 09.11.2026, приложенные скриншоты и `Untitled (4).fig`. Figma MCP вернул лимит Starter; тариф не менялся. Локальный архив прочитан: DEFLATE schema + Zstandard message + Kiwi, 981 узел. База заставки 390×844, frame 1009:113: круг языка 64×64 (164,208), соседние 42/50 px; поле 314×50 (39,302); стихотворение (44,403); глаз 70×50 (161,736). Исходные SVG и Inter сохранены.

## Реализация кандидата

- Заставка: видимая карусель языков, пять пузырей в области просмотра, центр выбирается при остановке; поле сообщает язык продолжения. Смена обновляет весь локальный UI через сохранённую локализацию, пользовательский текст не переводится. Управление свайпом, мышью, wheel, клавиатурой; десять языков.
- Вход только свайпом вверх или прежним доступным глазом. Первый запуск нового оформления, включая обновление со старой тёмной базы, голубой; последующий выбор темы сохраняется. Нет добавленных кнопок и ссылок. Пустой основной экран без обучающего блока.
- Три темы выбираются кружками в строке «Тема → …», без отдельной полосы крупных кнопок. Независимая стрелка настроек сохранена.
- Из личного режима: влево — настройки, вправо — океан. Собственные жесты холста, карусели и карточки сохранены. Правый переход снимает открытое меню перед океаном.
- Тап по выбранному планктону открывает отдельный кабинет: имя, цвет свечения, размер, скорость и включение движения предпросмотра. Эти настройки локальны, не означают работу автономного ИИ. Имя/фото человека отдельно; существующий ключ профиля и native backup сохранены.

## Подключение сервера

Подключённым ИИ/общий океан не объявляются. Предыдущая проверка конфигурации 42553911071 не нашла собственные SSH/API/Ocean/OAuth настройки в OSMINOG/osminog-reg. Для новой проверки добавлены точные имена параметров API; значения не выводятся. АвтоЦена не используется.

Владелец уже выбрал REG Qwen 3.8 Flash Next. Точные API URL, host и model ID нужно взять из «Инструкция для API» этой карточки, а не угадывать. Секрет API и отдельный SSH-доступ сохраняются в GitHub environment `osminog-reg` репозитория OSMINOG. Инструкция: `docs/mobile/REG-CONNECTION.md`.

Адаптер REG в pilot.3 / PR #105 относится к подбору опубликованных мыслей. Он НЕ личный разговорный мозг/память/автономный агент. Старый pilot со SQLite для содержимого нельзя разворачивать без переработки под последнее требование: переписка и медиа на устройствах, сервер соединяет участников. Сначала отдельный доступ и проверка протокола/инфраструктуры, затем реальный обмен двух устройств и один проверенный вызов модели.
