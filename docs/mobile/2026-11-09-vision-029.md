# Vision 0.2.9 — профиль и жесты намерений

Статус: кандидат, публикация ещё не подтверждена.

## Основание

Поручение владельца 2026-11-09 и локальный `Untitled (3).fig`. Осьминог — поиск актуальных намерений в моменте. Совпадение и присутствие нельзя подменять анимацией или фиктивными участниками. Завершение исключает мысль из актуального пространства; удаление отдельно удаляет запись/вложения с устройства.

## Изменения кандидата

- Имя сохраняется при вводе. Инициализация карусели не считается выбором другого персонажа и не стирает фото.
- Копия профиля хранится также в private SharedPreferences приложения, восстанавливается при отсутствии WebView-профиля. Обычное обновление с той же подписью сохраняет каталог; удаление приложения/очистка данных может удалить обе копии. Облачное восстановление не обещается.
- Карточка мысли закреплена снизу, имеет промежуточное/полное положения, движется за жестом, закрывается вниз. Полный вид показывает автора над карточкой, заголовок и медиа/обсуждение внутри.
- Медиа в личной записи размещены отдельной строкой ниже текста. Меню действий закрываются тапом по свободной области.
- Собственный профиль: имя, фото, описание, актуальные намерения, галерея вложений.
- Третья тема «Классика»: белый фон, тёмный текст, список намерений вместо пузырей.
- Явная кнопка начала, объяснение проекта, повторный показ знакомства, локальный выход без удаления файлов. Это не OAuth logout: сетевого аккаунта пока нет.

## Проверка доступности конфигурации

Собственный workflow: https://github.com/jeep-jim/OSMINOG/actions/runs/42542556520 . Он проверил только наличие значений в OSMINOG / osminog-reg; не подключался к серверу, не раскрывал значений, не обращался к другим проектам.

На момент запуска недоступны `OSMINOG_REG_SSH_KEY`, `OSMINOG_REG_AI_API_KEY`, `OSMINOG_OCEAN_URL`, `OSMINOG_GOOGLE_WEB_CLIENT_ID`, `OSMINOG_TELEGRAM_CLIENT_ID`. Это не утверждение об отсутствии настроек у провайдеров под другими именами; это конкретные отсутствующие входы данного проекта.

Для живого этапа нужны собственный ограниченный доступ OSMINOG к REG, HTTPS endpoint сервиса, зарегистрированные OAuth-клиенты с корректными redirect/package/certificate и проверкой токенов на стороне сервиса. Ключи вводятся в окружение проекта, не в чат/исходники/APK. В текущем APK нет имитации входа или сетевой публикации. Проверка двух устройств остаётся незавершённой.

## Проверки

JS syntax и контроль исходных SVG пройдены локально. Подготовлено 63 Android-теста: новые проверки профиля/восстановления, карусели, геометрии и жестов панели, Classic, повторного знакомства, профиля/медиа, фона меню, завершения и размещения фото, синхронизации открытой карточки после редактирования/удаления. Голосовые fake-service тесты не заменяют акустическую проверку на телефоне. Подписанное обновление планируется 0.2.8 → 0.2.9 без удаления между установками.
