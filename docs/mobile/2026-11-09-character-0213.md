## Реализация в работе

Отдельный stateless Python gateway под osminog, порт 3081; TLS с собственным сертификатом, который Android будет доверять только для фиксированного адреса. Никаких изменений nginx, Docker, DNS или другого проекта. Постоянные данные — только хеши анонимных сессий и счётчики лимитов; содержание чатов/камеры/мыслей не пишется в базу или логи. REG получает только явно разрешённый текущий запрос и ограниченный контекст; его политика хранения не равна нашей локальной политике.

Лимиты gateway: 256 MiB, 25% одного CPU, 32 задачи, максимум 12 сетевых обработчиков и два модельных запроса одновременно; 300 запросов/UTC-сутки всего, 100 на сессию, 30 запросов с изображением всего. Это ограничения запросов/ресурсов, не обещание конкретного денежного бюджета. Нет бесконечного анализа камеры в фоне. Кадр — один на отправку при согласии; камера выключается при уходе из приложения. Опубликованных чужих мыслей сервис не выдумывает. Общий межпользовательский океан этим выпуском не запускается; исследуются реальные мысли на устройстве.

Локально 13 серверных unit-тестов прошли, bash/YAML проверены. Реальный deployment, Android-приёмка и публикация пока не заявляются.
