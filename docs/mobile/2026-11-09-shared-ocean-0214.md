# 0.2.14 — общий океан и ссылка установки

Прямое поручение владельца: сразу подключить общий океан других пользователей для проверки с двух телефонов, добавить отправку ссылки установки рядом с версией после проверки актуальности, опубликовать подписанный APK.

Реализация кандидата: явно подтверждённые публичные текстовые мысли, ответы между анонимными устройствами, серверные проверки владельца, блокировка/жалоба, удаление с каскадом ответов. Личные чаты, камера, вложения и старые черновики автоматически не публикуются. Публичные мысли хранятся 14 дней; максимум 30 на устройство / 1000 всего / 100 ответов в ветке. В первой выдаче последние 40 разрешённых мыслей. Обновление открытого океана/обсуждения раз в 10 секунд, только на переднем плане; ручное обновление. Авторизация хранится только нативно на устройстве и не истекает через 30 дней, чтобы не потерять право удаления. Удаление приложения теряет доступ автора; общего аккаунта/восстановления ещё нет. Публичная БД только /opt/osminog/character/state/ocean.sqlite; личный REG-чат по-прежнему не сохраняется gateway. Те же ограничения user systemd и собственный сертификат; АвтоЦена не изменяется.

Локально прошли 22 серверных теста (13 прежних + 9 общего океана). Новая проверка двух независимых браузерных клиентов использует локальный HTTP тестовый backend и явно тестовые данные; реальный сервер проверяется отдельным TLS smoke с удалением временной публикации. В этой среде локальный Chromium не запускается из-за запрета socket(), поэтому UI/Android приемка выполняется в собственном GitHub Actions. Успех и публикация пока не заявляются.

Первый browser CI42598263181/motion-and-palettes SUCCESS: normal/reduced motion, character/camera fixtures и два отдельных UI-клиента на локальном сервере прошли. Просмотрены оба скриншота: публичный ответ доставлен. Исправлены подпись автора (общий океан вместо «на устройстве»), стиль удаления ответа; поиск отправляет запрос на сервер по всем доступным активным мыслям (выдача до 40). Новый каталог 308 ключей на 10 языках. Первый deploy стартовал, но старый smoke ожидал storesContent=false; это устаревший контракт после добавления публичных записей. Проверка заменена на storesPrivateChat=false + ocean=true, отдельный TLS сценарий сохраняет/удаляет тестовую публикацию. Публикация APK ещё не заявляется.
