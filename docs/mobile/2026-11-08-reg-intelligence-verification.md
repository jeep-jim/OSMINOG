# 2026-11-08 — внутренний интеллект REG: журнал реализации и проверки

Дополнение к `OSMINOG_MOBILE_ROADMAP.md`. Новое прямое поручение владельца:
использовать выделенную в присланном каталоге REG модель **Qwen 3.8 Flash Next**
для внутреннего интеллекта. Это ограниченное разрешение на REG API для подбора
намерений, а не на GPU, произвольных провайдеров или старые сторонние веб-чаты.
Границы разделения проектов остаются неизменными; АвтоЦена в этой работе не
читалась, не изменялась и не использовалась для доступа/выполнения операций.

## Что действительно сохранено

[PR #105](https://github.com/jeep-jim/OSMINOG/pull/105), ветка
`feat/intent-ocean-pilot-20261107`, commit
**38e7cdb2379585caf78de02f8fdee741d1fb3123**. Общая версия Web/PWA/APK:
**0.3.0-pilot.3**, Android versionCode **9**. Ветка обновлена fast-forward с
проверкой ожидаемого родителя cb73e1175ad03a2c39d1935b620dd67228e1c209.

Добавлены серверный адаптер REG, явное согласие в профиле, фильтры приватности,
лимиты, кеш, отдельный журнал usage и конфигурационный overlay. Модель выбирает
только номера реально существующих доступных намерений; не создаёт людей и не
пишет за них. Кандидатов максимум 24, поэтому полнота поиска по всему океану не
заявляется. Частные записи, черновики, беседы, имена/профили и вложения не уходят
провайдеру. Простая очистка контактов не является гарантией анонимности текста.

Согласие по умолчанию выключено, включая существующих пользователей. Доступ,
срок, блокировка и согласие проверяются до и после запроса. Сеть не держит общую
блокировку SQLite. Ошибка, лимит и отсутствие конфигурации оставляют обычный
подбор по словам. Оплачиваемый вызов — только защищённый POST магнита; GET и
набор текста его не запускают. Лимиты: один вызов одновременно, 10/мин,
100/UTC-сутки, вход до 18 000 байт, max_tokens 512, кеш 120 секунд. Это не
денежная гарантия: тариф и действительный usage ещё требуется проверить.

## Сервер, модель и точный следующий шаг

Скриншоты владельца подтверждают выбранную REG VM 8120751, IP 151.248.113.177,
8 vCPU / 16 ГБ RAM / 100 ГБ диска. Это характеристики тарифа, не замер свободных
ресурсов. Собственный SSH OSMINOG всё ещё не предоставлен; факт существования
VM и модели не даёт приложению отдельного доступа.

Цены модели на скрине: 30 ₽ / млн входных, 90 ₽ / млн выходных. Условный пример
1000 входных + 200 выходных токенов: 0,03 + 0,018 = **0,048 ₽**. Это не средняя
цена запроса и не проверка счёта провайдера.

Точный API base URL и model ID из карточки не видны, публичными источниками не
подтверждены; они сознательно НЕ угаданы. Нужно нажать **«Инструкция для API»**
именно у выбранной модели и получить параметры без секретов. Отдельный ключ
ИИ-платформы сохраняется непосредственно в собственном GitHub environment
`osminog-reg` как `OSMINOG_REG_AI_API_KEY`, не передаётся в чат/Git/клиент.
Он не заменяет SSH-ключ `OSMINOG_REG_SSH_KEY`. Сохранение секрета в GitHub не
является доставкой его на VM. Подробности подключения в ветке:
`infra/intent-ocean/REG-AI.md` и `compose.reg-ai.yaml`.

Живой запрос REG, установка на VM, DNS/HTTPS, подписанный APK, тест телефона,
миграция истории, восстановление/удаление аккаунтов и эксплуатационная готовность
остаются незавершёнными. Новые тарифы/мощности не покупались. Код добавлен;
реальное подключение модели и публикация сервиса **не заявляются**.
