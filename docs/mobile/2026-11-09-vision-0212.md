# Vision 0.2.12 — читаемость, движение и подключение REG

Прямые требования владельца сохранены в основном mobile roadmap. Восстановлены подъём пузырей и поочерёдное появление строк без изменения макета заставки. В Океане текст настроек белый 100%; светлая палитра явно инвертирует текст, иконки, поля и листы. Убраны псевдоэлементы восьмёрки, возвращён плавный овальный зрачок из прежней композиции. Состояния: бесцветное ожидание, жёлтый реальный запрос, красный ввод, сиреневая запись голоса. Нет выдуманного мышления при локальном сохранении.

Кабинет персонажа использует стеклянный предпросмотр, семь цветных пузырей и выбор собственного цвета, компактные строки с текущими значениями. Сохранение имени/фото человека, параметров персонажа и native backup не меняется. Отдельный exitButton удалён; единственный вход в заставку — О проекте → Посмотреть вступление.

Из присланной инструкции REG подтверждены https://ai.reg.cloud/v1, ai.reg.cloud, qwen-3.8-flash-next. Конфигурация несекретна и хранится в config/reg-ai.json. Отдельная собственная workflow выполняет один ограниченный синтетический запрос, если доступен API-ключ. Ключ не попадает в Git, APK, журнал или диагностический ответ. Тесты транспорта используют mock и не считаются живым соединением. Общий сервер, личный чат и автономность не объявляются подключёнными по результату этого smoke test. SSH OSMINOG проверяется отдельно; доступы АвтоЦены не используются.

Статус: кандидат, не публикация. Локально пройдены синтаксис, каталог 245 обязательных ключей на 10 языках, оригинальные ассеты и шесть контрактных проверок REG probe. Добавлены Android-проверки анимации, контраста обеих палитр, гладкой формы глаза/цветов и цветовой палитры. Обязательны Android CI, снимки, прежняя подпись и обновление поверх 0.2.11 перед переключением канала.
