# 2026-11-08 — REG Qwen для внутреннего подбора намерений

Датированное дополнение к OSMINOG_MOBILE_ROADMAP.md. Предыдущее состояние:
[пилот.2](2026-11-07-pilot2-progress.md). Правило
[разделения проектов](2026-11-07-project-isolation.md) остаётся обязательным.

## Решение владельца и подтверждённые входные данные

Владелец прислал скриншоты REG и прямо поручил использовать показанную модель
Alibaba для внутреннего интеллекта. Выделенная карточка: **Qwen 3.8 Flash Next**,
«Внутренняя», 30 ₽ за миллион входных и 90 ₽ за миллион выходных токенов.
Это цены на предоставленном скриншоте, а не результат тарификационного запроса.
Разрешение касается REG API для ограниченного подбора намерений, не установки
крупной LLM на VM, не GPU и не возвращения веб-чатов сторонних провайдеров.

Скрин VM показывает ID 8120751, IP 151.248.113.177, 8 vCPU, 16 ГБ RAM,
100 ГБ диска и активный статус. Это выделенные ресурсы, НЕ измеренный свободный
запас. Отдельный SSH-доступ OSMINOG скриншотом не предоставлен. Заходить через
репозиторий, ключи или процессы другого проекта по-прежнему нельзя.

## Выполненный код кандидата 0.3.0-pilot.3

- `services/intent-ocean/reg_ai.py`: отключаемый по умолчанию серверный адаптер
  Chat Completions, с обязательными точными base URL/host/model. Адрес и ID не
  выдумываются из отображаемого названия. Только HTTPS к явно закреплённому
  REG-хосту, без перенаправления ключа и без неявных прокси.
- Модель получает только разрешённые активные намерения и временные номера;
  не получает имена/аккаунты, переписку, личные заметки, черновики и файлы.
  Распространённые ссылки/телефоны/email вычищаются; полной анонимности текста
  это не гарантирует. Согласие по умолчанию выключено и доступно в профиле.
- Подбор обрабатывает до 24 кандидатов (часть по словам, часть свежих, в том
  числе без общих слов). Это ограниченный пилот, не полный смысловой индекс.
- Ответ — строгий JSON, только существующие номера из текущего списка;
  модель не может создать человека/пузырь или отправить сообщение от него.
- Права/блокировка/актуальность/согласие проверяются до и после сетевого вызова.
  Сеть не держит общий lock БД, поэтому получение ответа не блокирует
  обычный чат, выход, блокировку и отзыв согласия.
- При отключении, неверной конфигурации, сбое или лимите сохраняется явно
  обозначенный подбор по словам. Никакого скрытого перехода к другому ИИ.
- Один запрос одновременно, 10/мин и 100/UTC-сутки с постоянным счётчиком;
  максимум 18 000 байт входного JSON и max_tokens=512. Кеш 120 секунд, без
  текста в постоянном журнале. Денежный потолок этим не обещается: требуется
  проверить фактическую тарификацию, ограничения и usage REG.
- Общие Web/PWA и Android файлы обновлены до pilot.3, versionCode 9. Базовый
  compose не включает модель; для включения существует отдельный overlay.

## Проверено локально

35 серверных и контрактных тестов завершились OK, включая 15 прежних и 20
новых: ограничения, ошибки/недопустимые ID, приватность, CSRF, кеш, лимит после
перезапуска, блокировка/выход/отзыв согласия во время запроса. JavaScript syntax
checks прошли. В этих тестах ответ модели даёт **локальный тестовый транспорт**,
а не Qwen REG. Они подтверждают обработку границ, но не качество живой модели.

Браузерная проверка новой формы, CI-сборка APK и конечные результаты CI должны
быть зафиксированы отдельно после запуска. Локальные тесты не равны публикации.

## Не подключено и не опубликовано

Секрет модели, точный URL и API model ID не получены. Живых платных вызовов REG
не выполнялось. Сохранение кода/секрета в GitHub само по себе не устанавливает
приложение на VM и не доставляет туда настройки. SSH, установка, DNS/HTTPS,
проверка настоящего телефона, подпись APK и обновление канала не выполнялись.
На этой итерации АвтоЦена не читалась, не изменялась и не использовалась.

## Следующий шаг

Владелец открывает «Инструкция для API» именно у Qwen 3.8 Flash Next и передаёт
base URL и model ID без секретного ключа. Для модели нужен отдельный ключ
ИИ-платформы OSMINOG, не SSH-ключ/токен управления сервером. Инструкция безопасной
конфигурации и секретов: `infra/intent-ocean/REG-AI.md`. Для установки приложения
по-прежнему требуется отдельный серверный доступ OSMINOG. Не заявлять,
что присутствие карточки модели означает уже настроенный интеллект приложения.
