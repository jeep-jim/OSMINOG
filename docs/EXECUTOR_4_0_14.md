# Исполнитель 4.0.14

Команда пишется в обычной вкладке ИИ. Автопилот в шапке разрешает безопасные действия; отправка требует подтверждения. Действия выполняет отдельный исполнитель, результат показывается плашкой Осьминога. Исходное сообщение не переписывается.

- browser_read: исполнитель по умолчанию запрашивает includeScreenshot:false. Видимый canvas включает изображение автоматически. includeScreenshot:true принудительно запрашивает снимок. После действия режим чтения сохраняется.
- web_image_search возвращает assetRef, название, адрес источника и MIME; байты остаются в памяти задачи. asset_create {assetRef,name} помещает эти байты на холст. Идентификатор другой/завершённой задачи не принимается.
- Источник разговора — ограниченный фрагмент текущего чата без полей ввода, недоверенная справка. Последние команды и итоги хранятся только в памяти, отдельно для каждого проекта/маршрута/ревизии доступа, 30 минут.
- Этапы ожидания: чтение контекста, сессионный ответ, загрузка служебной вкладки, ответ служебной вкладки. Итог выводится в плашке рядом с сообщением.
- Служебная вкладка не замедляет таймеры. Команда со снимком не отправляется, пока адаптер не увидел подтверждение вложения.

Проверки Windows используют контролируемые страницы. Они не удостоверяют живые GPT/DeepSeek/Claude или Figma. Отдельный служебный исполнитель не является native tools того же видимого облачного диалога.
