## Runtime and remaining limitations

Build with `python3 light/build.py`. Ship this allowlisted 22-file package, not root `editor.js`/`background.js` or the historical full-workspace build. Root manifest/source stay as historical compatibility material. Viewport ≤120 metadata records and ≤24 stored small image previews; drag persists one coordinate record at completion. Fixed sidebar has no resize handler. Full text is opened and edited separately. Only GPT/DeepSeek explicit requests; no live paid API call is claimed.

Free: three desks and 100 image imports/captures per UTC month. Pro proposal $6.99/month: 10,000 images/month, 1,000 desks and streamed ZIP. Production entitlement is Free; no checkout, billing or subscription activation.

Old originals are not deleted. Explicit per-item IDB migration exists, but the old `briefCraftStudioV2` monolithic snapshot and historical creative objects/journals are not fully migrated. The UI discloses this. Never claim a complete archive migration or delete/reinstall the user's old extension/profile. No automatic snapshot measurement: Chromium SettingsStorageQuotaEnforcer::GetBytesInUse calls LazyCalculateUsage, which reads the full delegate store. New update markers use IDB and consume the old exact-key marker without writing/removing the old Chrome store.
Source inspection: https://chromium.googlesource.com/chromium/src/+/refs/heads/main/extensions/browser/api/storage/settings_storage_quota_enforcer.cc

Owner hardware acceptance, complete old snapshot migration, paid entitlement backend, signed/notarized desktop distribution, and desktop auto-update remain separate work. No remote installation on the owner's computer is asserted.
