# 15.10.2026 — сравнение подключения 0.3.9 и 4.0.4

Сравнены ab3e5d6 (desktop/package.json: 0.3.9) и e4ae4dd (4.0.4). Electron 44.5.0 и desktop/network.cjs не изменились. Добавлены сессионный API-транспорт, скрытые служебные диалоги и запуск из события отправки.

Подтверждённые изменения поведения:
- probe возвращал ошибку API сразу, не проверяя готовую открытую страницу. Восстановлена резервная DOM-проверка; два отказа не дают успешного статуса.
- page:user-send отправлялся в capture-фазе Enter до обработчика сайта. Теперь ожидается очистка composer, без изменения пользовательского текста и повторной отправки. Неочищенный или изменённый черновик не запускает исполнителя.

13 целевых unit-тестов прошли. Windows CI и реальные авторизованные аккаунты ещё не подтверждены для этой правки. Очистка composer является сигналом обработки отправки интерфейсом, а не доказательством получения ответа сервера. Ошибки живых ChatGPT/DeepSeek не объявлены устранёнными. Изменений движка, прокси, cookies и формата проекта нет.
