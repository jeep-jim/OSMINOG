# Вложения служебного чата — 4.0.16

При невозможности отправить изображение исполнитель останавливается до отправки команды. Снимок не отбрасывается ради продолжения без визуальных данных.

Адаптер ищет подходящее активное поле файла; при его отсутствии открывает распознанную кнопку прикрепления. Поддержаны MIME и расширения в accept. Если поля нет, используется paste в composer. Подтверждение проверяется только в composer: нужны все новые превью (включая HTTP(S)) либо имена всех новых файлов, отсутствие признака загрузки и стабильность 600 мс. Максимальное ожидание — 20 секунд. Один FileList и совпадение имени в истории не являются подтверждением.

После прикрепления поле ввода ищется заново, чтобы обновлённый сайтом composer получил команду. Непустой черновик не перезаписывается. Сообщение отправляется однократно; подтверждение отправки и ответ проверяются прежним механизмом.

Ошибки:
- ATTACHMENT_INVALID — файл не подготовлен;
- ATTACHMENT_COMPOSER_MISSING — поле ввода отсутствует;
- ATTACHMENT_MULTIPLE_UNSUPPORTED — поле допускает только один файл;
- ATTACHMENT_REJECTED — сайт показал ошибку загрузки;
- ATTACHMENT_NOT_READY — готовность не подтверждена, в сообщении указаны способ, число новых превью и признак загрузки.

Регрессия проверяется на контролируемых страницах в настоящем Electron на Windows, включая установленную копию. Это не подтверждает работоспособность каждого текущего интерфейса живого аккаунта провайдера.
