В пилоте нет восстановления пароля. Сохрани его в менеджере паролей.
Разрешаю передавать REG текст моих активных намерений «В океан» для подбора по смыслу. Личные записи, черновики, беседы и вложения не передаются. Выключение прекращает новые отправки, но не отзывает уже переданные данные.

По умолчанию магнит подбирает по словам. ИИ REG используется только с отдельным разрешением и при доступном подключении; его оценки могут ошибаться. Намерения активны 24 часа; черновик никому не виден.
