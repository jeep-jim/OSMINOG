# OSMINOG 4.0.39 — возврат прежнего приложения

По требованию владельца отменена замена редактора на упрощённую версию 4.0.38. Возвращены интерфейс и набор возможностей Chrome 4.0.37. Номер 4.0.39 позволяет установить этот возврат поверх 4.0.38 обычным обновлением.

## Что возвращено

- Прежний бесконечный холст, столы, папки, слои, файлы и связи между объектами.
- Редактирование фотографий и векторов, документы и прежние варианты экспорта.
- Снимки экрана, поиск сохранённых материалов и распознавание текста.
- Прежний чат справа, вкладки агентов, подключения, доступ и инструменты работы с исходным кодом.
- Настройки, темы и элементы управления из 4.0.37.

## Исправления без замены интерфейса

- Шапка сохраняет положение при открытии боковых панелей; панели располагаются под ней.
- Новые текстовые карточки из буфера и 4.0.38 используют читаемый цвет текущей темы. Оформление ранее сохранённых объектов сохраняется.
- Холст не создаёт элементы для объектов далеко за границами видимой области. Объекты остаются в проекте и доступны поиску, экспорту и инструментам; при перемещении холста они снова отображаются.
- Повторная отрисовка сохраняет неизменившиеся элементы вместо повторного создания изображений. Активное редактирование и выделение сохраняются.
- При переключении существующего стола записывается только выбранный стол, без сохранения всей медиатеки, резервной копии и ревизии. Выбор восстанавливается после перезапуска; ожидающие записи изменений сохраняются.
- Неизменившиеся подписи, счётчики и координаты папок не переписываются при каждом обновлении холста. Изменения содержимого и положения папки отображаются сразу.
- Обновление ожидает завершения записей и сохраняет изменения, но не создаёт новую полную резервную копию, ревизию и экспорт папки, когда это не требуется для перезапуска.
- При обычном сохранении снимок изменяемых структур создаётся без повторного преобразования всех изображений в JSON. Изменения, внесённые во время сохранения, остаются отмеченными как несохранённые.
- Сохранены отдельные записи перемещений и захваченных материалов, объединение повторных операций и оптимизация счётчиков папок из предыдущих исправлений.

## Данные и обновление

Материалы и переписка, сохранённые в 4.0.38, переносятся в прежний рабочий интерфейс. Исходные базы 4.0.38 сохраняются; перед изменением прежних записей создаётся резервная копия. Перенос должен завершиться до открытия проекта.

Постоянный ключ расширения и Owner Authenticator сохраняются. Модуль обновления 2.0.0 и проверка запуска новой версии остаются прежними.

В 4.0.38 используйте кнопку версии / проверки обновлений для установки 4.0.39. Для установки, в которой старая кнопка приводит к зависанию, к выпуску прилагается `OSMINOG-Update-Recovery.html`: открыть в Chrome, выбрать существующую папку расширения, установить исправление и завершить обновление через значок расширения. Вручную распаковывать ZIP или удалять расширение не требуется.

## Границы проверки

Публиковать разрешено только точный пакет после успешных автоматических проверок восстановленного интерфейса, материалов 4.0.38, фонового буфера и обновления в настоящем Chromium. Результаты и ссылки на конкретные проверки фиксируются в журнале проекта после их завершения.

`runtimeVerified` остаётся `false`: измерения на компьютере владельца отсутствуют. Проверки в Linux Chromium не являются гарантией отсутствия любых сбоев Chrome на Windows.
