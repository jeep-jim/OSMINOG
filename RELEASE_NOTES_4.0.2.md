# OSMINOG 4.0.2 · Visual Runtime

- При ошибке подготовки контекста внешний чат отключает перехват. Черновик сохраняется; повторная отправка работает без холста и без автоматической повторной отправки.
- Статус подключения уточнён: включён мост, данные передаются по запросу.
- Восстановлена загрузка изолированного runtime виджетов: исправлена причина `Module Studio unavailable`.
- Сохранённые приложения доступны из «Ещё → Мои виджеты и приложения».
- Генерация растровых изображений больше не получает противоречивое требование вернуть правки из примитивов.
- Импорт обрабатывает все полученные изображения, сохраняет пропорции и размещает их рядом. Исходные байты не пережимаются.
- Контракт раскадровки требует согласованности персонажа. 3D-рендер не выдаётся за готовую 3D-модель.

Генератор изображений остаётся зависимым от подключённого провайдера и его сеанса. Новый движок генерации или 3D-моделирования этой сборкой не подключён. Проверки с тестовым провайдером не подтверждают качество живой генерации.
