# 4.0.20 — Сохранение в папку и локальный поиск

- В шапке: сбор из буфера, календарь и поиск. Переключатель «Новый мир» убран; столы остаются в боковой навигации.
- Автосбор включается пользователем после выбора папки. Назначение закреплено при переходе между столами. Пауза прекращает чтение буфера. Очередь хранится локально до открытия редактора.
- Индексация русского/английского текста изображений локальным Tesseract; текстовых файлов и PDF (включая OCR сканов). Другие файлы находятся по названию. Ошибки распознавания показаны в результатах.
- Календарь фильтрует дату сохранения новых материалов. Старые даты не выдумываются.
- Кнопка Google скрыта при отсутствии OAuth-конфигурации. Синхронизация столов и файлов между устройствами в этот выпуск НЕ входит.

Ограничения: нужен запущенный Chrome; собираются текст и изображения из буфера, а не файлы, скопированные в Проводнике. Материалы больше 18 МБ показывают ошибку. Содержимое буфера при включении пропускается. OCR обрабатывается последовательно при открытом редакторе. Если браузер запрещает фоновое чтение буфера, ошибка видна в настройках сбора.
