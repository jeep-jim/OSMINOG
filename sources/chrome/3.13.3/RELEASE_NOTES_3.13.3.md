# OSMINOG Chrome 3.13.3 — UNIFIED BROWSER AND ACCESS

## Исправлено

- «Редактировать вёрстку» больше не закрывает новый браузер и не создаёт старый browser-объект на холсте.
- Редактор страницы работает внутри приложения «Браузер»: вкладки, выбор, перемещение, изменение размера, текст, цвета, прозрачность, HTML и локальное сохранение макета.
- ИИ-сервисы можно открыть во внутренней вкладке OSMINOG; авторизованные web-сессии подключаются из того же экрана.
- Права холста, Poseidon, папка исходников, GitHub, подключения ИИ, ссылка и роли людей собраны в едином центре.
- Старые дублирующие окна подключений и общего доступа больше не используются как точки входа.
- Свернутые системные окна больше не порождают справа в доке мелкие буквенные иконки.

## Важно о входе в сервисы

Сайты, запрещающие встраивание через CSP/X-Frame-Options, могут потребовать отдельную авторизованную вкладку Chrome. OSMINOG управляет её подключением и синхронизацией из единого центра, а обычные и совместимые страницы открывает во внутренних вкладках.
