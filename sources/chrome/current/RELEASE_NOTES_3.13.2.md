# OSMINOG Chrome 3.13.2 — WINDOWS AND GRAPHICS HOTFIX

- Unifies focus, minimize and close controls into one stable shelf in every managed window header.
- Every opened or restored window is raised above existing windows with a single global z-order.
- Minimized secondary windows are restored from the dock; permanent applications keep their normal dock icon.
- Removes the dock's white/glass container in every theme while keeping the independent color artwork icons.
- Replaces the black Nano Banana mark with a dimensional yellow banana artwork.
- Opens chat directly on the latest message while it is hidden, eliminating the visible top-to-bottom history scroll.
- Incoming AI output preserves the reader's current scroll position instead of forcing the view to the bottom.
- Adds a full offline Graphics application powered by the bundled MIT-licensed Fabric.js engine: select, brush, pen, line, rectangle, ellipse, text and image tools; central canvas; explicit tool apply; properties; geometry; layers; undo/redo; grouping; PNG export and transfer to the OSMINOG canvas.
- Restores the Browser action for opening a compatible page in OSMINOG's editable layout-snapshot mode.
- Keeps module details on the right, makes the center splitter draggable, protects system modules from deletion and exposes deletion only for removable user modules.
