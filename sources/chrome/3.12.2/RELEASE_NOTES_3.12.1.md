# OSMINOG 3.12.1 — Native Widgets

- Виджеты и инструменты открываются самостоятельными элементами без большого окна приложения.
- Невидимый sandbox автоматически принимает размер фактического содержимого.
- Перемещение, редактирование и закрытие доступны компактными кнопками только при наведении.
- Полноразмерные контейнеры сохранены только для типов `app` и `connector`.
- Манифест пользовательского модуля поддерживает явные `width` и `height` как стартовый размер.
