# OSMINOG Chrome 4.0.31

- Восстановлен штатный Browser App вместо упрощённой iframe-панели.
- Компактные вкладки с плюсом после вкладок; адресная строка ограничена по ширине.
- Браузер пристыкован к рабочей области, делится со столом регулируемым разделителем и расширяется при закрытии чата.
- ChatGPT/Figma открываются через управляемые вкладки Chrome того же профиля, с системным VPN и расширениями.
- Добавлен перенос выбранных изображений, видео, аудио и CSS background-image на стол из режима «Редактировать вёрстку» через Project API. Удалённые файлы требуют явного разрешения на домен.
- Если файл недоступен или сайт запрещает чтение, OSMINOG сообщает об ошибке, не имитируя успешный перенос.
- Authenticator сохранён без изменений.
