# OSMINOG Chrome 4.0.22 — Workspace Unification

## Русский
- Сохранение браузера дожидается записи проекта, раскладки и открытых вкладок.
- Материалы из папок открываются непосредственно в блокноте или редакторе изображений.
- Восстановлена третья вкладка «Папки» в разделе «Слои».
- Поиск поддерживает выбор отдельных или всех показанных материалов, групповое удаление с подтверждением и Undo/Redo.
- В диалоге подтверждения работают стрелки клавиатуры и Enter.
- Нижняя панель: выбор, рука, квадрат/круг, дополнительное меню, скриншот, отмена и повтор. Скрытую панель возвращает карандаш в шапке.
- Скриншот открывается в полном редакторе визуального контекста с выделением области и аннотациями.
- Кнопки шапки выровнены по размеру; исправлены отступы стрелок выпадающих списков.
- Новые панели выходят на передний план. Область обрезки изображения перемещается и изменяется за восемь маркеров.
- Добавлены настройки шрифта проекта, режим браузера на рабочую область и упрощённый первый запуск.
- Изменения компактной панели относятся к Chrome; собственная оболочка Windows сохранена.

## English
- Save waits for project, browser layout and open-tab persistence.
- Folder material opens directly in the notebook or image editor; the third Folders tab is restored in Layers.
- Search supports individual/all-visible selection, confirmed bulk deletion and Undo/Redo. Confirmation dialogs support arrow keys and Enter.
- Compact dock: selection, hand, square/circle, overflow, screenshot, Undo and Redo. The header pencil restores the hidden dock.
- Screenshot opens the full visual-context editor with region selection and annotations.
- Header buttons have consistent dimensions and dropdown arrows have corrected spacing. New panels come to the front; crop regions move and resize with eight handles.
- Project font settings, full-workspace browser mode and a simpler first-run screen are included.
- Chrome dock styling does not replace the native Windows shell.
