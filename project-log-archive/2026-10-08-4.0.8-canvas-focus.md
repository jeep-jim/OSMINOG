# 2026-10-08 — OSMINOG 4.0.8 Canvas Focus

Запрос владельца: Ctrl + \ как в Figma (доска без панелей), больше рабочая область, обычный текст прямо на холсте вместо диалога блокнота, активная точка, понятные иконки без маленьких стрелок. Предыдущий запрос: нижняя плавающая панель рисования.

База: main 22f85bae2bc6547e27dba947402ec3c400932734 / Chrome 4.0.7. Изменения изолированы в ветке codex/canvas-focus-text-408.

Реализовано: отдельный модуль osminog-canvas-ux.js/css; подключение через существующий Workdesk; прямое включение основных инструментов, дополнительные команды по правой кнопке/удержанию/ArrowDown; плавающая нижняя панель и её скрытие/возврат; полный focus toggle с восстановлением геометрии; обычные type=text объекты с contenteditable и типографикой справа; 0,5%–800% масштаб; расширенная логическая DOM/SVG-плоскость; SVG-иконки, индикаторы и ластик штрихов с Undo.

Проверено локально: 23 сценария настоящей страницы редактора в Chromium, Chrome API и хранилище заменены тестовыми реализациями. Нет ошибок JavaScript. Проверены обе темы, Ctrl + Backslash с физическим кодом клавиши, сохранение текста через штатный persist, точность координат и отсутствие горизонтального переполнения панели на узких экранах. Скриншоты и JSON-отчёт генерирует tests/canvas-ux-408.cjs.

Проверки прежнего shared-board теста сохранены; старое требование панели в шапке заменено требованием нижнего расположения, создание блокнота переведено на отдельный пункт note. Остальные регрессии остаются в CI. Статус полного CI нужно читать из результатов GitHub Actions, а не выводить из локального прогона.

Не менялось: формат хранения и существующие объекты владельца; фиксированный ключ расширения и разрешения; внешний/внутренний AI transport; приватность переписки; серверная архитектура; нативный обновлятор. Нет миграции и автоматической установки на компьютер владельца.

Доставка: CI формирует полную сборку и пакет изменённых файлов для установленной 4.0.7. Перед заменой локальных файлов — сохранение работы и резервная копия; расширение не удалять. Проверка на реальном профиле владельца остаётся отдельной от браузерных fixture-тестов.
