# 2026-10-08 — 4.0.8 опубликована для обновления по кнопке

## Требование владельца

Обычное обновление OSMINOG выполняется существующей кнопкой в браузере. Не предлагать владельцу повторное скачивание ZIP, распаковку, замену файлов, переустановку или новую папку вместо уже работающего обновления. Предложенная ранее ручная доставка 4.0.8 была ошибкой: source merge и CI artifact сами по себе не обновляют dev feed.

## Фактическое исправление

Код updater и локальный способ установки не менялись. Проверено: editor.js использует OSMINOGFolderUpdater.check/update; кнопка версии открывает проверку, «Обновить сейчас» запускает установку, затем chrome.runtime.reload(). Канал читается из jeep-jim/OSMINOG-Releases/channels/dev/chrome-extension.json.

До публикации канал оставался на 4.0.7. В 2026-10-08T04:45:28Z существующий publish-chrome-package-v2.yml продвинул его на 4.0.8 после загрузки и проверки полного GitHub Release asset.

- Все 124 распакованных файла побайтово соответствуют проверенной CI-сборке bbd2abb5aac7f9388bb3ceb8395a5e500df6e600, run 37726977016. ZIP детерминированно перепакован, поэтому контейнерный SHA отличается от исходного CI ZIP, а содержимое файлов — нет.

## Границы подтверждения

Публикация и доступность пакета/канала проверены. Установка в реальном профиле владельца не выполнялась; runtimeVerified оставлен false. Подпись feed была null и осталась null; проверки SHA-256, размера и идентичности расширения не отключались. Это dev-channel bootstrap, не утверждение о подписанном production feed.

Пользовательский путь: версия в шапке OSMINOG → «Доступна v4.0.8» → «Обновить сейчас». Если уже открыт результат старой проверки, выполнить проверку повторно. После успешной установки версия в шапке должна быть 4.0.8.

## Правило дальнейших релизов

Перед сообщением «обновляйся по кнопке» проверить не только source/main и CI, но и: полную опубликованную сборку, реальный asset size/hash, новую версию в dev feed и доступность raw feed. Не подменять этот процесс выдачей архива пользователю. Историю прошлых работ не перезаписывать.
