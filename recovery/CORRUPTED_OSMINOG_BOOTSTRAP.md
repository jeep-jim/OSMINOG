# Corrupted OSMINOG bootstrap record

Date: 2026-08-27

The file formerly stored as `bootstrap/osminog-source.zip` must never be used as source or as a release artifact.

## Evidence

- Git blob SHA: `a8be50f5f81275ea6d32587204b293676ba1216e`
- Size: `15009` bytes
- SHA-256 measured by GitHub Actions: `93921ebd4307e57b7cfc0c5a34d45d1daeca0cee942a8932cb33ccd9a8a6169b`
- `Expand-Archive` failed on the Windows runner.
- A second extraction attempt with `tar` listed several entries, then failed while decompressing `roadmap.md` with `ZIP decompression failed (-3)`.
- The bundle is therefore incomplete/corrupt and cannot serve as canonical source.

## Decision

The corrupt archive and its bootstrap extraction workflow are removed. OSMINOG source files must be committed directly or generated by CI from complete committed source. Binary bootstrap bundles are not accepted as project memory.
