# Desktop: актуальное направление Mac от 13.11.2026

Для macOS новое прямое поручение владельца — **Quadro Browser**, универсальный многооконный браузер для M1 Pro. Сначала читать `docs/desktop/2026-11-13-quadro-browser.md`. Это решение заменяет торговую концепцию Trader OS из верхней части `OSMINOG_BROWSER_ROADMAP.md` только для Mac; старую историю не удалять и не возвращать торговые панели при последующих правках.

Mac runtime: `quadro-main.cjs`, `quadro-preload.cjs`, `quadro-update.cjs`, `quadro-build.cjs`, `quadro/`. Сборка/проверка — `.github/workflows/quadro-macos.yml`, распространение — отдельный `quadro-macos-vVERSION-arm64` в OSMINOG-Releases. Windows/Chrome/Android каналы и АвтоЦена не входят в эту задачу.

Не возвращать левую колонку, тикеры/watchlist/рынки/скальпинг, торговые подсказки или macOS Tray/status-item. Правые ИИ-сайты — обычные sandboxed страницы по пользовательской HTTP(S)-ссылке; не включать автоматический доступ ИИ к другим страницам и данным. Границы нативных окон должны соответствовать DOM после любого resize, открытия/закрытия чата и диалога. Сохранять размеры и страницы без reload при перетаскивании. Проверять реальные pointer events и обе темы в установленном arm64 приложении.

Имена `Trader OS` в пути профиля, `trader-os-main`, `traderWalletWatch` и Chromium partition намеренно сохранены как внутренние миграционные ключи. Их переименование без миграции потеряет доступ к прежним данным. В видимом новом интерфейсе используется Quadro Browser. Не удалять пользовательский профиль, вкладки, cookies или публичные адреса.

Кошелёк сейчас watch-only, не MetaMask и не подписывающий модуль. Не принимать seed/privateKey и не изображать подпись/отправку работающими.

Установленная 5.0.3 не имеет автоматического updater: первый переход только новым DMG после полного выхода из старого приложения. Quadro проверяет отдельный канал, скачивает и проверяет SHA-256, открывает DMG; копирование приложения остаётся ручным. Ad-hoc подпись не является Developer ID/notarization. Не обещать полностью автоматическую установку и не отключать защиту macOS глобально.

Source PR130 проверен и объединён. Точное состояние публикации/URL/SHA-256 читать в журнале или проверять живым release API; один успешный коммит не означает публикацию или работу на Mac владельца.
