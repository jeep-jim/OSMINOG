# Mouse — macOS Apple Silicon

Сначала [краткая сводка](../MOUSE_BROWSER_ROADMAP.md), затем только документ текущей задачи: [6.0.44](../docs/desktop/2026-11-28-mouse644-filter-updates-page-themes.md). История — в Git и адресных документах, не в повторно загружаемых больших журналах.

**До новой команды владельца — только Mac Apple Silicon и при необходимости сайт. Windows/Linux не разрабатывать, не собирать, не публиковать.** Их выпуски/каналы 6.0.42 и историю сохранять; перенос Mac-изменений требует нового поручения.

## Код и совместимость

- Имя установленного приложения: **Mouse**, без Browser/«Браузер»; домен `mouse.black`. Исходники: `mouse-main.cjs`, `mouse-preload.cjs`, `mouse-update.cjs`, `mouse-build.cjs`, `mouse/`. Проверка: `../.github/workflows/mouse-macos.yml`, `../tools/mouse-verify.py`.
- Сохранять профиль, App ID, Chromium partition, cookies, вкладки, столы и служебные ключи. Не менять действующие адреса обновления и опубликованные подписанные/хешированные пакеты без совместимого перехода. Переименование приложения не разрешает удаление/перенос пользовательских данных или других платформ.
- Норка — графический знак новой вкладки; команда и Cmd+T прежние. Маскот, очки, постоянная чёрная мышь на белом в Dock не меняются без прямой просьбы.
- Плиточный поиск и встроенный Agent Mouse отменены. Не возвращать Agent runtime/IPC/UI/настройки, Local MCP, терминал, исполнителя и модельные подключения ради старых тестов. Обычные сайты боковой ИИ-панели остаются. Файлы, drag/drop, скругления и установщик — самостоятельные функции браузера.
- Старые агентские столы переводить в обычные, сохраняя вкладки, содержимое, историю и профиль. Исторические журналы и пакеты не переписывать; в новых тестах проверять отсутствие агента. [Решение и доказательства](../docs/desktop/2026-11-22-mouse637-agent-removal.md).

## Проверка и пределы

Проверять реальные действия установленной arm64-сборки, обе темы, инкогнито, перезапуск, сохранение профиля и обновление из опубликованной версии. Сохранять обязательные gates; готовность объявлять после проверки пакета, канала и публикации.

Mac — предварительная ad-hoc сборка без Developer ID/нотариализации. Не отключать защиту macOS или sandbox. Кошелёк и web3-провайдер удалены из Mouse; не возвращать их ради старых тестов, прежние пользовательские данные сохранять.
