# OSMINOG 3.11.55 — CUSTOM EXTENSION STUDIO

- Dedicated extension registry and manifest metadata.
- Draggable desktop launcher outside canvas selection.
- Independent interactive, draggable and resizable application window.
- Built-in code editor, type selector, update and confirmed delete controls.
- Buttons, forms, scripts, downloads and modal interactions are enabled inside the sandbox.
- OSMINOG progress chatter no longer duplicates the provider response in chat.
- Legacy canvas applications remain available for compatibility; new builds use Extension Studio.
