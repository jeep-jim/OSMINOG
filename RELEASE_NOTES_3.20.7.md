# OSMINOG 3.20.7 — Animation Studio + Agent Media Recovery

В этот выпуск входит вся функциональность неопубликованной 3.20.6 и исправления внутреннего чата.

- Animation Studio: таймлайн, дорожки, ключевые кадры, easing, loop-preview, WebM/Lottie export и редактируемый объект анимации на рабочем столе.
- Команды изменения интерфейса OSMINOG снова маршрутизируются в source-edit даже когда в сообщении упомянуты холст или изображения.
- Команды «время под аватаром», «подними поле ввода», «поправь вёрстку чата» распознаются как правки продукта.
- ChatGPT-генерация возвращает реальное изображение в OSMINOG, а хост автоматически создаёт image-объект на холсте.
- Изображения, найденные в интернете, сохраняются через web_image_search → asset_create без фиктивного подтверждения.
- Нижняя панель чата закреплена внутри окна; время сообщений перенесено под аватары пользователя и агента.
- Сохранены Graphics Studio, прозрачный холст, PNG/export и предыдущие исправления 3.20.5.

Проверка живого провайдера всё ещё выполняется после установки: генерация зависит от доступности Image Generation в подключённой сессии ChatGPT.
