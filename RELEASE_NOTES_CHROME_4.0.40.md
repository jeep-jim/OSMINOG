# OSMINOG Chrome 4.0.40 — ограничение нагрузки боковой панели

Сохранён интерфейс и набор инструментов 4.0.39. Источником сравнения служит коммит 3cdc60a, в котором Chrome manifest действительно имеет версию 4.0.20. Ранее указанный в журнале e0e9917 содержит Chrome manifest 4.0.9 и не является точным исходником Chrome 4.0.20. Отдельный опубликованный Chrome 4.0.20 в текущем архиве выпусков не найден.

- Как в 4.0.20, настройка «Мини-превью слоёв» управляет загрузкой изображений; теперь она распространяется и на добавленный позднее список сохранённых материалов.
- Закрытая панель слоёв не строит список при первом обновлении. Оригиналы изображений для миниатюр подключаются только у видимых строк. При прокрутке и закрытии панели ссылки освобождаются.
- Изменение ширины боковых панелей сохраняет только размеры, без полной записи проектов, резервной копии и истории ревизий.
- Убрана отложенная установка фокуса на «Отмена», которая могла перехватывать фокус после нажатия стрелки. Закрытие подтверждения через Escape удаляет обработчик клавиатуры.

Оригинальные файлы, проекты, буфер, поиск, чат, инструменты и обновлятор сохранены. Новые проверки охватывают 80 миниатюр, отключённые превью, закрытие/открытие панели и 500 событий изменения ширины. Браузерная проверка включает изображения 3840×2160.

Это исправления подтверждённых путей лишней нагрузки, а не доказательство причины аварийного завершения Chrome на компьютере владельца. runtimeVerified=false до проверки владельцем. Публикация — только после успешных CI и проверки точного пакета.
