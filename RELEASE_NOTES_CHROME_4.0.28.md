# OSMINOG Chrome 4.0.28

Кандидат на выпуск: корзина проектов с подтверждением, восстановлением в течение семи дней и окончательным удалением; зелёная папка «Входящие», счётчик сегодняшних сохранений и переход из окна расширения на стол; увеличенные подписи и скрытая служебная папка хранилища на холсте.

Сохраняются исправления ограничения чтения папок, объединения записей и восстановления вкладки редактора после обновления. Поиск и обработка материалов запускаются по запросу.

Публикация допускается только после прохождения Chrome, Windows, документных, совместимых и новых браузерных проверок корзины. Установочный ZIP формируется проверенным workflow; канал получает его через существующий импорт CI с проверкой размера, SHA-256 и неизменного ключа расширения. Ручная переустановка пользователю не требуется.

Проверка на личном компьютере владельца отдельно не заявляется. Эта запись сама по себе не означает публикацию версии.
