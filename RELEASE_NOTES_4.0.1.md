# OSMINOG 4.0.1 · Header Tools

- Инструменты холста собраны по центру шапки в девять групп.
- Нажатие раскрывает функции; повторное нажатие, Escape и нажатие вне панели закрывают их.
- Markdown находится в «Текст»; обрезка, оригинал и копирование PNG — в «Снимки и изображения»; масштаб — в «Навигация».
- Старые панели инструментов и нижний блок масштаба скрыты, обработчики существующих действий сохранены.
- На узких окнах инструменты занимают вторую строку шапки, оставаясь сверху.
- Выбор рисования, фигуры или ноды открывает существующие настройки инструмента.
- Формат данных, ключ расширения и механизм обновления по кнопке не менялись.

Это первый шаг P1 / R18. Полная переработка редакторов, системного буфера, совместной работы и ИИ остаётся в roadmap.
