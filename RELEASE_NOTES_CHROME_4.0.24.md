# OSMINOG Chrome 4.0.24 — Performance Hotfix

## Исправление производительности

В 4.0.23 список слоёв начал заново создавать строки для всех сохранённых в папках материалов при каждой перерисовке. Дополнительно пустой поисковый запрос приводил к объединению и приведению к нижнему регистру полных текстов. Это создавало заметную нагрузку при большом архиве.

- В разделе материалов из папок одновременно отображается не более 80 строк; остальные доступны через страницы. Поиск по-прежнему проверяет весь архив.
- Неизменившийся список сохраняет существующие элементы интерфейса вместо полного пересоздания.
- Закрытая панель слоёв не перестраивается; при открытии отображается актуальное состояние.
- Пустой поиск больше не обрабатывает содержимое всех больших текстов.
- Счётчики папок продолжают обновляться, в том числе при скрытой панели, удалении и Undo.
- Данные проектов, материалы, идентификатор расширения и разрешения не меняются.

## Помощник

Изменены пропорции корпуса под знак OSMINOG. Добавлены медная текстура радужки и тёмный горизонтальный зрачок с двумя расширениями и суженной серединой. Взгляд следует направлению перемещения. Щупалец нет. Анимация выключается для неактивного помощника, скрытой вкладки и при системном предпочтении уменьшенного движения.

## Проверки и границы вывода

Добавлен тест на 1 200 сохранённых материалов: ограниченное число строк, переход по страницам, поиск по невидимым на текущей странице материалам, изменение текста, 120 повторных запросов перерисовки без пересоздания DOM, обновления статуса сборщика, скрытые слои, счётчики и Undo. Все прежние проверки остаются включены.

Это проверка воспроизведённой регрессии в тестовом окружении, а не измерение браузера владельца. Она не доказывает, что у конкретного пользователя исключены все возможные причины задержки 5–10 секунд. Проверка на личном компьютере владельца отдельно не выполнялась.

## English

Fixes the 4.0.23 large-archive Layers rendering regression. Stored rows are paged in batches of 80 while search still covers the entire archive. Identical redraws reuse DOM; hidden Layers defer rendering; empty queries do not copy and lowercase every note. Folder counters and Undo remain live. The assistant uses a logo-proportioned body, copper iris and dark horizontal figure-eight-shaped pupil; inactive, hidden-tab and reduced-motion animations are disabled. No user-data migration or extension identity/permission change.
