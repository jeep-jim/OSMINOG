# OSMINOG — внешний MCP: локальный пилот 0.1.0

Статус: отдельное экспериментальное подключение поверх OSMINOG 4.0.7.
Это не готовый коммерческий релиз и не автоматически установленный плагин ChatGPT.
Старый browser_presence и внутренний чат не изменены.

## Что реализовано

`ChatGPT → Secure MCP Tunnel → MCP stdio → локальный HTTP-мост → открытая доска`.

MCP-сервер использует Node.js 22+ без npm-зависимостей. Небольшой stdio-адаптер
реализует initialize, notifications/initialized, ping, tools/list, tools/call,
notifications/cancelled по MCP 2025-11-25; также согласует 2025-06-18/2024-11-05.
Это собственная реализация ограниченного tools-only транспорта, не полный MCP SDK.
Sampling, resources, prompts и Streamable HTTP здесь не заявлены.

12 инструментов чтения: текущий статус, карта, постраничный список, выделение,
объект, связи, поиск, последнее изменение, текст заметки, исходный код, document_read
и реальные пиксели встроенного растрового изображения. Два инструмента записи:
create_canvas_note и update_canvas_note. Другие действия старого ядра не открыты
через этот пилот: нет удаления, запуска кода, доступа к репозиторию и перепискам.

Каждый запрос идёт к живому редактору. Обзорная карта — не пиксельное зрение.
read_canvas_image возвращает MCP image content, а не строку imageAttached.
Это исходные пиксели вложенного PNG/JPEG/WebP/GIF с ограничением размера;
фильтры/маски холста и соседние стрелки не включены. SVG и удалённые URL не читаются.

## Подключение на Windows

1. Использовать файлы этой ветки поверх исходников 4.0.7. Для overlay-архива:
   сначала сделать резервную копию папки расширения, затем перенести файлы архива
   с сохранением структуры. Это дополнение, а не самостоятельное расширение.
   Перезагрузить существующее расширение и вкладку OSMINOG обычным способом.
2. Установить Node.js 22+ и официальный OpenAI tunnel-client. Создать туннель в
   OpenAI Platform, связать его с нужным ChatGPT workspace и выдать права Read + Use
   runtime-ключу. Управление туннелем и доступ custom MCP в ChatGPT — разные права.
3. Запустить `mcp/Start-OSMINOG-MCP.ps1` в соответствии с политикой выполнения
   PowerShell на компьютере. Ввести tunnel_id и runtime API key **в локальном окне**,
   не в чат. Скрипт не сохраняет ключ; он передаёт его tunnel-client через окружение.
   Windows launcher здесь предоставлен для проверки; на Windows он ещё не запускался.
4. После старта выбрать в OSMINOG: **Доступ → Внешний ChatGPT · MCP → файл**
   `%LOCALAPPDATA%\OSMINOG\mcp-pairing.json`. Выбрать «Только чтение» или
   «Чтение + создание и правка заметок», нажать «Подключить эту доску» и разрешить
   доступ к localhost. Файл содержит локальный секрет, его нельзя прикреплять к чату.
5. В ChatGPT: Plugins → плюс → Add custom MCP server → Connection: Tunnel.
   Выбрать свой туннель, проверить разрешения, создать подключение. Нужны права,
   доступные именно в используемом аккаунте/workspace. При изменении схем обновить
   metadata подключения. В этом репозитории нет доступа для выполнения этого шага
   от имени аккаунта владельца.
6. В тестовом разговоре вызвать canvas_status, get_selection, read_canvas_image.
   Затем попросить создать тестовую заметку, прочитать её обратно, обновить,
   повторить запрос с тем же requestKey и перезагрузить доску.

Ручная команда после настройки профиля: `tunnel-client run --profile osminog`.
Для иных MCP-клиентов, поддерживающих stdio: `node /absolute/path/OSMINOG/mcp/server.mjs`.
MCP отсутствует на HTTP localhost: этот порт — только аутентифицированный
редакторский транспорт. Не указывайте его как публичный MCP endpoint.

## Границы безопасности и восстановления

Сервер слушает только 127.0.0.1; случайный локальный токен — 32 байта.
Проверяются Host, Origin, токен, clientId, projectId, whitelist инструментов и аргументы.
Нет CORS-разрешения для сайтов. Только один явно подключённый проект.
Смена проекта, закрытие или отключение прекращают доступ; автоматического выбора
другой вкладки/доски и восстановления после перезагрузки нет.

Очередь ограничена 8 запросами, выполняется один запрос за раз. Таймаут — 25 секунд,
lease — 30 секунд. Доставленная мутация не запускается автоматически повторно.
Запись требует локальной роли edit и expectedRevision. requestKey связывается с
полными аргументами; повтор с изменённым содержимым отклоняется. Квитанции хранятся
в проекте (до 256, без автоматического удаления), включая после перезагрузки.
Сохранение проверяется через существующий persist редактора. При сбое сохранения
изменение может уже быть в памяти; ответ явно не сообщает успех. Повторять нужно
те же аргументы и тот же requestKey. Повтор возвращает первоначальный результат и
текущую revision/objectStillExists — он не доказывает, что текст после этого не меняли.
Обычный Undo редактора сохраняется, но восстановление старой версии всего проекта
может откатить и историю квитанций; после такого восстановления повторно проверить состояние.

Secure MCP Tunnel — отдельный компонент OpenAI: его доступность, авторизация,
ограничения аккаунта и коммерческие условия этим кодом не проверяются и не обещаются.
Для массового продукта ещё нужны удобная установка, эксплуатация и отдельная
проверка многопользовательской авторизации; этот мост single-user и не предназначен
для публичного размещения. Не публиковать локальный HTTP-порт через обычный proxy.

## Проверки

`node --test mcp/tests/bridge.test.mjs` из корня: 14 автоматических тестов.
`python mcp/tests/browser_test.py`: функциональный тест редактора в Chromium с
тестовыми Chrome API/storage и локальным HTTP proxy. Это НЕ проверка настоящих
Chrome permissions, аккаунта ChatGPT или Secure MCP Tunnel. Требует Python Playwright.
В контейнере запуска браузерные страницы блокирует managed policy; такой прогон
нельзя считать пройденным. Отдельный CI workflow выполняет этот тест в GitHub Actions.
