# OSMINOG Chrome 4.0.32 — экспериментальное магнитное окно

Обновление расширения поверх 4.0.31. Отдельное Windows-приложение не меняется.

- Живые сайты открываются в настоящих popup-окнах Chrome того же профиля. Внутренняя рамка OSMINOG задаёт положение и размер выбранного окна. Это отдельное окно ОС, а не встроенный WebContentsView и не iframe сайта.
- Каждая вкладка в панели OSMINOG получает своё окно Chrome; у рамки показывается только выбранное, остальные сворачиваются. Переключение сохраняет страницу без перезагрузки. Одновременно можно держать до восьми таких страниц.
- Нативные окна входа и страницы, открытые сайтом в новом окне, остаются отдельными: их контекст и отправленные формы не пересоздаются.
- Размер подстраивается при разделении стола, изменении чата и перемещении основного окна. В режиме «только стол» обе области скрываются.
- Изменение размеров не забирает фокус клавиатуры. Добавлена кнопка «Вернуть окно сайта к рамке» для явного возврата окна на передний план.
- Постоянного always-on-top нет: при работе с основным окном Chrome или другим приложением плавающее окно может оказаться позади. Это ограничение экспериментального режима, а не обещание полностью встроенного браузера.
- Сохранён перенос изображения из редактируемой копии сайта на стол. Чтение копии страницы требует разрешения доступа к её домену.
- Authenticator, ключ расширения, хранилища проектов и фоновые сессии ИИ сохранены. Дополнительные постоянные разрешения не запрашиваются.

Проверки выполняются на контролируемых страницах, включая страницу с запретом встраивания, окно с POST-формой, сохранение состояния вкладки и перенос изображения. Работа живых аккаунтов Figma/Google/ChatGPT и точность размещения на конкретном Windows-компьютере владельца отдельно не подтверждались.
