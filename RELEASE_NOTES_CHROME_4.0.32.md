# OSMINOG Chrome 4.0.32

- Живые сайты открываются не в iframe, а в настоящих вкладках Chrome того же профиля в отдельном popup-окне.
- Окно визуально «магнитится» поверх области просмотра Browser App, подгоняется по её геометрии и следует за изменением размеров стола/чата и перемещением главного окна Chrome.
- Вкладки OSMINOG управляют реальными Chrome tabs; target=_blank перенаправляется в то же плавающее окно.
- Google, Figma, ChatGPT и другие сайты используют текущую авторизацию, cookies, VPN и расширения Chrome.
- Редактор макетов получает DOM из активной вкладки после явного разрешения доступа к домену; сохранён перенос медиа из редактируемой копии.
- При переключении в режим «только стол» окно сворачивается; при возврате браузера восстанавливается.
- Chrome Extension API не даёт системного always-on-top: окно поднимается при открытии и переключении, но ОС может изменить z-order при фокусе других окон.
- Authenticator и отдельное Windows-приложение не изменялись.
